# 저장소 기본 도구를 사용한 기능 QA

새 하니스나 브라우저 대체 수단이 아닌, 문서화된 저장소 명령어, CLI/API 클라이언트,
작업/큐 도구를 사용합니다.

## 기능 모드

/qa 및 /qa-only에서는 선택한 범위 내에서 다음을 따릅니다.
- **전체**(기본값): 아래의 적용 가능한 문서화된 계약을 모두 다룹니다.
- **빠른 검사**(`--quick`): 성공과 위험도가 가장 높은 변경 경계를 검사하고, 다른
  계약은 실행하지 않음으로 표시합니다.
- **회귀**(`--regression <previous-report>`): 프로브 전에 제공된 기능 보고서와 연결된
  재현 증거를 읽습니다. 기준선이 없거나, 읽을 수 없거나, 대상이 잘못되면 회귀 모드가
  차단됩니다. 브라우저 전용 `baseline.json`은 기능 기준선이 아닙니다. 소유한 설정을
  다시 구성하고, 이전에 실패한 프로브를 기록된 버그 출력이 아닌 문서화된 기댓값에
  따라 재현한 뒤, 변경된 인접 동작을 검사합니다. 이전 보고서를 보존하고, 수정됨,
  계속 실패, 새 발견 사항을 별도로 보고합니다. 안전한 재현 입력이 없으면 영향을
  받는 프로브는 차단되며, 절대로 통과로 계산하지 않습니다.

혼합 실행에서는 각 표면의 모드를 별도로 적용합니다. /review 및 /ship은 전체 탐색이
아닌 호출자의 제한된 스모크 검사와 명시적 계획 검사를 유지합니다.

## 계약 맵

각 계약/출처, 격리된 설정, 정확한 프로브, 기댓값 및 결과를 기록합니다:
통과/실패/차단됨/실행하지 않음/결론 없음/해당 없음(사유).

| 계약 | 관찰 사항 |
|---|---|
| 성공적 실행 | 시작/수락뿐 아니라 예상된 반환값/출력 및 최종 비즈니스 효과 |
| 잘못되었거나 누락된 입력 | 각 필드의 문서화된 입력 규칙(허용 문자, 형식, 부호, 범위, 인수 개수)마다 해당 규칙만 위반하는 프로브 하나: 선언된 거부, 올바른 상태, 금지된 상태 변경 없음 |
| 인증/권한 부여 | 유효한 ID, 누락/잘못된 ID, 잘못된 소유자/역할, 지속되는 무효과 경계 |
| CLI 프로세스 계약 | 정확한 종료 코드, stdout 및 stderr를 별도로 기록; 결과 파일/상태 변경 |
| 상태 전이 | 초기, 중간, 완료/실패 상태 및 허용되는 전이 |
| 시간 초과/취소 | 마감 시간, 부분 상태, 소유 작업의 종료 및 복구 |
| 재시도 | 저장소가 약속한 시도 횟수/백오프/종료 상태; 무제한 재시도 없음 |
| 중복/멱등성 | 문서화된 보장 하에서 반복된 요청/이벤트 및 지속 효과 수 |
| 동시성/순서 | 관련된 두 완료 순서 모두에서 제어된 경쟁 작업; 최종 불변식 |
| 부분 실패 복구 | 효과 발생 후 중단, 재시작/재생, 완료/데드레터 상태와 중복 검사 |

보편적인 정확히 한 번 전달을 강제하지 마세요. 수락, 큐 등록, 처리, 재시도/데드레터 및
최종 효과를 분리하세요. 2xx는 완료가 아닙니다. 예상된 거부/주입된 실패는 통과할 수
있지만, 실행을 막는 누락된 서비스는 적용 범위를 차단합니다.

## 실행 및 증거 보존

1. 공통 격리/권한 사전 검사를 적용합니다. cwd, 명령어, 환경 변수 이름 및 안전한 초기화를
   확인하고, 합성 데이터/자격 증명을 사용합니다.
2. 공통 탐색 루프의 순서와 서면 체크포인트를 따릅니다. 모든 프로브에서 초기/최종
   지속 상태를 검사하고, 실패를 가리지 않으면서 종료/상태와 stdout/stderr를 별도로
   보존합니다.
3. 시간 초과 시 부분 출력/상태를 보존하고 소유한 작업만 중지합니다. 설정 오류와
   테스트하지 않은 계약을 기록하고, 누락된 전제 조건을 숨기기 위해 제품 코드를
   패치하지 마세요.
4. 정확한 명령 또는 메서드/경로/헤더/본문, 설정/초기화, 예상 계약/출처, 관찰된
   출력/상태, 리비전/런타임, 증거 경로와 한계를 기록합니다. 시크릿은 환경 변수
   이름으로만 참조합니다. 삭제 처리로 인한 재현 한계를 공개합니다.
5. 설치된 QA SKILL.md를 기준으로 상대 경로인 `templates/functional-report-template.md`를
   사용합니다. 소유한 정리 전에 증거를 보존하고 남은 항목을 공개합니다. 탐색 권한을
   확장하지 않고 호출자에게 반환합니다.
