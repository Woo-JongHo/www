# 유지보수성 전문가 검토 체크리스트

범위: 항상 활성화(모든 검토)
출력: 한 줄에 발견 사항 하나인 JSON 객체. 스키마:
{"severity":"INFORMATIONAL","confidence":N,"path":"file","line":N,"category":"maintainability","summary":"...","fix":"...","fingerprint":"path:line:maintainability","specialist":"maintainability"}
선택 사항: line, fix, fingerprint, evidence, test_stub.
발견 사항이 없는 경우: `NO FINDINGS`만 출력하고 다른 것은 출력하지 않는다.

## 범주

### 죽은 코드 및 사용하지 않는 임포트
- 변경된 파일에서 값을 할당했지만 한 번도 읽지 않는 변수
- 정의했지만 한 번도 호출하지 않는 함수/메서드(저장소 전체에서 Grep으로 확인)
- 변경 후 더 이상 참조하지 않는 imports/requires
- 주석 처리된 코드 블록(제거하거나 존재 이유를 설명)

### 매직 넘버 및 문자열 결합
- 로직에 그대로 사용된 숫자 리터럴(임계값, 한도, 재시도 횟수) — 이름 있는 상수여야 함
- 다른 곳에서 쿼리 필터나 조건문으로 사용하는 오류 메시지 문자열
- 설정이어야 하는 하드코딩된 URL, 포트 또는 호스트 이름
- 여러 파일에 중복된 리터럴 값

### 오래된 주석 및 독스트링
- 이 diff에서 코드가 변경된 뒤에도 이전 동작을 설명하는 주석
- 완료된 작업을 참조하는 TODO/FIXME 주석
- 현재 함수 시그니처와 매개변수 목록이 일치하지 않는 독스트링
- 더 이상 코드 흐름과 일치하지 않는 주석의 ASCII 다이어그램
- 이 diff에서 보호 조건은 변경됐지만 텍스트는 변경되지 않은 사용자 대상 문자열(오류, 토스트, 레이블)

### 결함이 있는 중복 동작
- 잘못된 결과를 낸다는 사실이 입증되었거나, 필수 오류 처리를 누락했거나, 동일한 계약을 위반하는 서로 달라진 복사본
- 일반적인 Fix-First 처리 방식으로 구체적인 결함과 그 증거를 보고한다. 구문이 일치하거나 줄 수가 반복된다는 사실만으로는 발견 사항이 아니다
- 선택적인 공유 헬퍼 추출은 핵심 공유 코드 검사에 속한다. 그 제안을 중복하거나 구조적 선호를 결함으로 바꾸지 않는다

### 조건부 부수 효과
- 조건에 따라 분기하지만 한 분기에서 부수 효과를 누락한 코드 경로
- 작업이 조건에 따라 건너뛰어졌는데도 작업이 수행됐다고 주장하는 로그 메시지
- 한 분기는 관련 레코드를 갱신하지만 다른 분기는 갱신하지 않는 상태 전이
- 정상 경로에서만 발생하고 오류/경계 경로에서는 누락되는 이벤트 방출

### 모듈 경계 위반
- 다른 모듈의 내부 구현에 접근(관례상 private인 메서드에 접근)
- 서비스/모델을 거쳐야 하는 컨트롤러/뷰의 직접 데이터베이스 쿼리
- 인터페이스를 통해 통신해야 하는 컴포넌트 사이의 강한 결합
