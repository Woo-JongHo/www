# 교차검증 사용량 보기

기존 검토 이력과 원문 영수증에서 만든 파생 요약이다. 한 실제 호출은 한 행으로 세고, 여러 작업에 연결한 같은 호출을 중복 합산하지 않는다. 값이 없으면 미확인으로 남긴다.

## 호출별 기록

| 실행·검토 ID | 작업·기준 | 종류 | 요청·관측 모델 | 소스·패킷 식별 | 판정·후속 지적 | 원문 영수증 |
|---|---|---|---|---|---|---|

## 사용량

| 실행·검토 ID | 신규 입력 | 캐시 생성 | 캐시 읽기 | 출력 | 내부 턴 | CLI API 환산액 | 집계 상태 |
|---|---|---|---|---|---|---|---|

집계 상태는 실제 제공 / 일부 누락 / 미제공을 구분한다. reasoning이 출력에 포함된 경우 중복 합산하지 않는다. 캐시 읽기는 누적 처리량이며 고유 자료량이나 실제 구독 한도 차감량으로 환산하지 않는다. 환산액을 실제 청구액으로 표시하지 않는다.

|---|---|

| 완료 정책상 남은 검토 | |
| 다음 호출 또는 종료 이유 | |

패킷·원문·지적이 같고 유효한 결과가 있으면 기존 core의 재사용 판단을 먼저 확인한다. 실패를 삭제하거나 예산 부족을 통과로 바꾸지 않는다. 범위와 완료 조건이 다른 호출끼리 절감률을 계산하지 않는다.
