# WWW 디자인 시스템

WWW는 로컬 개발의 요청·공개 과정·관측된 실행·결과를 읽는 작업 공간이다. 첫 적용 범위는 Chat 007의 명령 카드와 실시간 세션 모니터다. 역할과 인계는 [WWW 디자인 에이전트](../agents/www-design/AGENT.md), 기능 의미는 [Chat 명세](specs/chat.md), 구현·검증 상태는 [Chat 007 작업 기록](work/Chat/007-%EC%8B%A4%EC%8B%9C%EA%B0%84%20%EC%84%B8%EC%85%98%20%EB%AA%A8%EB%8B%88%ED%84%B0%EC%99%80%20%EC%B1%84%ED%8C%85%20%EA%B0%80%EB%8F%85%EC%84%B1/work.json)에서 확인한다.

## 원칙과 정본

본문은 요청부터 공개 설명·도구·답변 순서로 읽고, 오른쪽 패널은 현재 상태와 질문별 근거를 빠르게 찾게 한다. 상태 색은 실제 관측에 대응하며 문구·아이콘을 함께 표시한다. 기술 식별자와 출력은 상세에 두고 기본 안내는 한국어로 쓴다.

실행 토큰의 정본은 `src/index.html`의 기본 CSS 변수와 `src/chat.css`의 Chat 의미 변수다. 오른쪽 패널의 `src/native-activity.css`는 같은 의미를 참조한다. 아래 값은 이번 설계의 근거가 된 기존 팔레트이며 값 변경 시 실제 CSS를 먼저 확인한다. 이 문서를 별도 테마 설정으로 실행하지 않는다.

| 역할 | 기존 변수와 기준 색 | 사용 |
|---|---|---|
| 화면·출력 바탕 | `--bg` #0b0b0c | 대화·출력 배경 |
| 카드·표면 | `--surface` #111113, `--raised` #18181b | 카드와 펼침·선택 구분 |
| 본문·보조 글자 | `--text` #ececee, `--muted` #8b8b92 | 출력·본문과 시간·출처 |
| 진행·포커스 | `--accent` #8ab4ff | 실행 중·링크·키보드 포커스 |
| 완료 | `--ok` #4ade80 | 실제 정상 종료 |
| 대기·미확인 | `--warn` #f5b740 | 승인 대기·종료 누락·연결 경고 |
| 실패 | `--error` #f87171 | 관측된 오류·실패 |

Chat 카드의 의미 변수는 `--chat-card-surface`, `--chat-card-border`, `--chat-card-radius`, `--chat-state-running`, `--chat-state-failed`, `--chat-state-unknown`, `--chat-space`, `--chat-font-mono`다. 색은 기존 변수를 참조하고 새 컴포넌트마다 원시 색을 복제하지 않는다.

## 글자·간격·형태

본문은 시스템 한글 글꼴 13px와 넉넉한 행간을 사용한다. 명령·출력은 12px/1.65의 시스템 고정폭 글꼴이며 본문 전체를 고정폭으로 만들지 않는다. 상호작용의 이름·상태·질문은 일반 글꼴로 읽는다. 보조 시각 정보는 본문보다 작게 두되 중요한 상태는 보조 정보로 내리지 않는다.

기본 읽기 여백은 `--chat-space` 16px, 카드 내부는 12px/14px, 테두리는 1px, 카드 모서리는 `--chat-card-radius` 8px다. 상위 구조는 구획선으로 나누고 같은 정보를 여러 장의 카드에 반복하지 않는다. 모션은 실행 중임을 알리는 작은 표시로 제한한다.

## 컴포넌트와 상태

| 컴포넌트 | 기본 표시·상호작용 | 확인할 상태 |
|---|---|---|
| 명령 카드 | 상태·경과 시간, 명령, 제공된 cwd, 최대 10줄 미리보기, 보관 출력 펼침 | 실행·완료·실패·중단·미확인·출력 없음·미리보기 생략·보관 절단 |
| 실시간 모니터 | 현재 작업과 마지막 활동, 선택한 질문의 흐름, 현재 작업 복귀 | 연결·승인 대기·오류·조용한 대기·이력 복원·정보 미제공 |
| Skill·Hook 활동 | 종류·이름·문구·아이콘·시각 | 요청·읽기 시작/완료/실패, Hook 실행/완료/실패/차단/중단·종료 누락 |
| 메시지 | Markdown 본문·표·코드, 공개 설명과 최종 답변의 구분 | 스트리밍·완료·원문 절단·긴 URL·긴 코드·빈 본문 |
| 입력 | Enter 전송·Shift+Enter 줄바꿈, 보존된 초안 | 한글 조합·전송 중·오류·비활성·키보드 포커스 |

명령 미리보기는 실행 중 최근 10개 논리 줄, 정상 종료 뒤 앞 10개 논리 줄을 보인다. 실패 출력은 기본 펼침으로 안내하고 사용자의 수동 선택은 갱신 뒤에도 보존한다. 공백·탭·줄바꿈을 보존하고 긴 줄은 출력 영역 안에서 가로 스크롤한다. 보관하지 않은 원문은 펼침·복사로 복구된다고 표현하지 않는다.

‘읽기 완료’는 Skill 적용 완료가 아니며 턴 종료는 개별 도구 성공이 아니다. 공개 설명이 없으면 상태 안내와 실제 도구 상태를 보이고 과정 문장을 만들어 채우지 않는다. 정확한 사건 의미는 기능 명세가 소유한다.

## 반응형·접근성

넓은 창은 왼쪽 탐색·본문·오른쪽 360px 모니터를 사용한다. 1100px 이하에서는 탐색·패널을 줄이고, 999px 이하에서는 본문 폭을 확보하며 모니터를 접거나 별도 겹침 보기로 연다. 창 크기 변경과 패널 전환 후에도 입력과 답변 마지막 문장에 접근할 수 있어야 한다. 이 폭은 현재 파일럿 값이며 전체 기기의 검증 결과가 아니다.

본문 컨테이너는 `min-height: 0`과 내부 세로 스크롤을 사용한다. 표·코드만 필요한 가로 스크롤을 갖고 긴 URL은 줄바꿈한다. 과거를 읽는 동안 위치를 보존하며 새 내용으로 복귀하는 동작을 제공한다. 키보드로 본문·출력 스크롤, 펼침, 질문 선택, 최신 복귀와 입력에 접근한다. 포커스는 2px의 accent 외곽선으로 표시한다.

색에만 의미를 맡기지 않고 상태 문구와 아이콘을 함께 쓴다. `prefers-reduced-motion: reduce`에서는 반복 애니메이션과 부드러운 자동 스크롤을 끈다. 실제 대비·키보드·포커스·한국어 IME·창 배치 결과는 구현 검증 기록에 남긴다.

## 인계와 검증

디자인 변경은 해당 작업의 수용 기준, 수정 CSS·컴포넌트, 상태별 기대 동작과 실제 GUI 근거로 인계한다. 명령 출력 0·1·10·11줄, 대량·긴 줄·들여쓰기·오류·중단·종료 누락, 긴 Markdown의 마지막 문장, 과거 선택 중 새 활동, 연결 끊김, 좁은 창·모션 축소·키보드를 최소 확인한다. 문서 작성만으로 파일럿 적용이나 호스트 등록이 완료됐다고 기록하지 않는다.

## WWW 전용 흐름의 위계

현재 요청 요약 뒤에 전용 에이전트 둘과 개발 스킬 여섯을 표시한다. 요청·읽는 중·읽기 완료·실패·미관측을 글자로 구별하고 리터럴 cat 참조는 '읽기 명령 관측'과 비어 있는 사각 신호로 표시해 실제 읽기 성공이나 적용 완료로 보이게 하지 않는다. 범용 Hook·전체 명령과 모델·토큰은 접힘 상세에 둔다. Hook 실패와 신뢰 검토 필요 건수는 요약에서 확인하고 사용자 펼침은 질문별로 보존한다.
