사이드바 탐색과 작업 화면 분리 평가

프로젝트 목록 탐색만으로 중앙 작업 화면이 바뀌지 않도록 하는 개선안을 제시했습니다. 코드 확인과 사용성 평가만 진행했으며 구현은 하지 않았습니다.

사용자는 ‘전체 보기’로 돌아갈 때 현재 작업 페이지까지 사라지는 불편을 제기했습니다. Native 답변은 코드 확인을 근거로 사이드바 탐색과 중앙 화면 전환이 결합되어 있다고 설명했습니다. 이에 프로젝트 목록 탐색과 현재 프로젝트 재선택에서는 작업 화면을 유지하는 개선안을 제시했습니다. 이번 작업은 평가에 한정되며, 실제 수정과 UI 검증은 후속 작업으로 남았습니다.

선택 목록 탐색은 중앙 화면을 유지하고, 다른 프로젝트 선택은 화면을 전환하도록 권고했습니다.
