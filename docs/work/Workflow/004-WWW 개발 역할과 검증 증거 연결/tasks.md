# 구현 작업

## 단위 1: 기준과 개발 역할

- 변경: 제품·구조·Chat 기준, 공통 계약·역할·스킬의 권한과 정본 연결.
- 관련 기준: `AC-1`.
- 확인: 로컬 링크·정본 참조·현재 구현·미확인 구분.

## 단위 2: 접수와 증거

- 변경: 작업 생성·재개, 역할 선택 라우팅, 소스·기준 지문, 실제 검증과 완료 판단.
- 관련 기준: `AC-2`, `AC-3`.
- 확인: 실제 임시 Git 저장소와 subprocess를 사용하는 양성·음성 검사.

## 단위 3: 호스트·검토·앱 연결

- 변경: Codex 역할 수용, 공유 검토 정책과 앱 배포.
- 관련 기준: `AC-4`, `AC-6`, `AC-7`.
- 확인: 실제 호스트 실행, 배포 경로의 정책 로딩, 지정 모델 읽기 전용 검토와 실패 분류.

## 단위 4: 실제 Chat 변경과 재개

- 변경: 재현된 중단 RPC 접수와 실제 턴 종료 사이 상태 문제를 별도 버그 작업으로 수정.
- 관련 기준: `AC-5`.
- 확인: 원래 재현, 회귀 검사, 새 세션의 같은 UUID·현재 증거·다음 행동 수행.

## 직접 영향받는 후속 변경

문서·스킬·작업 스키마와 검증기가 일치하는지 통합 검사했다. 실제 Opus의 전체 최종 감사는 통과했고, 실제 영수증 검증과 현재 증거에 따른 완료 결과는 같은 작업의 `work.json`·`verification.md`에 연결한다. 인증 등의 검토 미실행은 구현·테스트 결과와 구분한다.
