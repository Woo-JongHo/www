# 선택 라이브러리 잔여 의미 18문구 교정

## 요청과 목적

기존 W005가 소유하는 선택 라이브러리 201자료 안의 잔여 의미 교정 하위 단위다. 새 라이브러리·제품 기능·권한 표면을 추가하지 않는다. 기존 W005 정확 경로 목록을 수기로 넓히지 않고 새로 확인한 5경로를 포함한 이번 7파일·18문구만 공식 접수한다. W005의 기준·검토·완료 영수증은 이 하위 단위의 결과로 대체하지 않으며 각각 고유하게 회수한다. 현재 원문/번역과 독립 반박이 결속된 선별 patch만 적용한다. 커밋·게시·전역 변경은 금지다.

사용자의 직접 요청으로 접수했다. 요청 식별값은 work.json의 workflow.requestHash에 보존한다.

## 범위

변경 경로·표면·검증 명령과 커밋·게시 권한은 work.json의 workflow.authorization을 따른다. 범위 확대는 기존 권한으로 간주하지 않는다.

## 수용 기준

정의와 필수 여부의 정본은 work.json이다. 관련 기준: `MATERIAL-18`, `LIBRARY-INTEGRITY`, `PARENT-TRACE`.

## 결정과 열린 질문

작업 접수는 구현 완료가 아니다. 재개 시 같은 UUID와 현재 증거를 확인한다.
