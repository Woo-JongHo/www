# 구현·검증 단위

1. 소스 확인용 읽기 명령과 변경/검사 실행 금지를 분리했다.
2. 새 plain Terra 응답과 초기 CLI 모델 헤더를 분리하고 legacy JSONL 영수증의 호출 형식 검증을 유지했다.
3. 요청 모델을 관측값으로 복사하지 않고 누락·중복·위조 위치·다른 모델·권한/argv·스키마·영수증 변조를 검사한다.
4. 현재 source에서 집중 검사·타입·소스 정책·빌드와 실제 읽기 전용 검토를 수행한다. 실제 모델의 실패/한도는 통과로 옮기지 않는다.

정본 수용 기준은 work.json이다. fixture와 실제 모델 실행은 구분하고 기존 UI 작업 005와 연결한다. 사용자가 지시한 worktree에서만 수행하며 원본·커밋·push·병합은 건드리지 않는다.

## 최종 마감 — 2026-11-15

현재 소스의 실제 Terra CLI PASS와 공유 core 영수증 수용을 확보했다. 필수 수용 기준과 문서 영향 검토가 모두 충족됐다. 상세 근거는 verification.md의 최종 실제 검토 절 및 reports의 완료 보고서에서 읽는다. 이전 대기·실패 절은 당시 이력으로 보존한다. 원본·커밋·push·병합·worktree 삭제·앱 종료는 수행하지 않는다.
