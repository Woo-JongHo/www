# 작업 내부 모델 배분과 실행 근거 연결

## 요청과 목적

작업 내부 모델 배분과 실행 근거 연결

사용자의 직접 요청으로 접수했다. 요청 식별값은 work.json의 workflow.requestHash에 보존한다.

## 범위

변경 경로·표면·검증 명령과 커밋·게시 권한은 work.json의 workflow.authorization을 따른다. 범위 확대는 기존 권한으로 간주하지 않는다.

## 수용 기준

정의와 필수 여부의 정본은 work.json이다. 관련 기준: `MODEL-PLAN`, `MODEL-RUN`, `MODEL-VERIFY`.

## 결정과 열린 질문

작업 접수는 구현 완료가 아니다. 재개 시 같은 UUID와 현재 증거를 확인한다.

## 최종 감사의 기록 경로 보완

Opus 1차 감사는 모델 배분 역할 참조인 agents/www/AGENT.md가 현재 쓰기 목록과 문서 검토에서 누락됐음을 지적했다. 사용자 직접 요청의 스킬·하네스 적재와 각 작업 내부 모델 배분을 역할 진입점에 연결하는 필수 변경으로, 새로운 제품·게시 권한을 추가한 것이 아니다. 원래 요청에 필요한 정확한 역할 문서 경로와 영향 검토를 원장에 보완했다. 1차 반려 원문과 당시 미검증 관측은 보존하고 최신 기록을 다시 감사한다.


## 최신 직접 Terra 감사 결정

2026-11-16 사용자가 “Terra로 감사진행해야지. 이거 계속 막히네, Claude가 없으면 Terra로 ㅐ”라고 직접 지정했다. 이전의 이번 세션 Opus 고정·대체 금지는 이 최신 결정으로 대체한다. 그 이전 Opus 호출·판정은 당시 이력으로 보존한다. 이번 현재성 복구의 감사는 기존 공유 core reviewAuthority에 이 원문·요청해시·workRequestHash·canonical source·기준·정책을 결합하고 별도 읽기 전용 Terra app-server 문맥에서 실행한다. 요청 모델과 실제 server-selected 관측, 주입 여부·읽기 범위·누락 입력을 구분한다. 일반 정책JSON이나 코드의 자동 fallback 조건을 이 문서만으로 바꾸지 않는다.
