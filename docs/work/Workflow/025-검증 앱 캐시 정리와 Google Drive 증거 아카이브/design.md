# 검증 증거의 로컬 보존과 Drive 아카이브

채팅·홈 Electron 검증은 실행이 끝난 뒤 격리된 프로필에서 Chromium 캐시 디렉터리만 정리한다. 같은 프로필을 사용하는 검증 중 재시작과 실패 증거 수집을 마친 뒤 수행한다. 실제 사용자의 앱 프로필과 테스트 프로필의 설정·원장은 보존한다.

Google Drive는 독립적으로 실행할 수 있는 rclone 연결을 사용한다. 날짜 기준 없이 검증 종류·범위·검사 목록이 같은 후속 성공본이 있는 경우에만 이전 성공 폴더의 최상위 산출물을 후보로 표시한다. 영수증·요약·실패 자료·프로필과 로컬 작업 문서에서 참조하는 실행은 보존한다. 후보 중 명시적으로 선택한 파일을 이동하며 원격 데이터를 다시 읽어 SHA-256과 크기를 확인한 뒤에 로컬 원본을 정리한다. 복원은 같은 로컬 경로를 사용하고 기존 파일을 덮어쓰지 않는다. 아카이브 영수증은 로컬에 남겨 기존 하네스 영수증과 별개로 이동 위치와 해시를 추적한다.

검증은 격리 프로필 정리, 정책상 제외, 업로드 실패·변조 시 원본 보존, 검증된 복사 뒤 삭제 및 복원으로 구성한다. 실제 Google Drive 연결과 권한은 별도 확인한다.
