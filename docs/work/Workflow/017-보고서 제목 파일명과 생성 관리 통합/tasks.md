# 구현과 검증 단위

1. AC-1: 안정 제목 파일명과 schema2 누적 writer, 내보내기 이름을 연결하고 동일 제목 반복 생성·동시 append·dedupe를 검사한다.
2. AC-2: 두 legacy 파일명과 bundle을 함께 읽고 모든 entry UUID·객체·의미지문·백업을 대조하며 실제 기존 자료를 병합한다.
3. AC-3: 전체 preflight·명시 적용·충돌 거부·JSON commit/HTML 복구·잔류 잠금 명시 회수와 재실행 수렴을 검사한다.
4. AC-4: 스킬·발견 링크·정본 계약·개발 안내·기능 명세를 병합 정책으로 갱신하고 공식 CLI를 실행한다.
5. AC-5: 서비스 목록 한 항목·최신 저작 우선·모든 이력의 안전한 HTML·요청 UUID 당시 내용 보존을 검사한다.
6. AC-1~AC-5: 후보 고정 후 집중 테스트·타입·소스 정책·구조·빌드·BoxBox 한계를 기록하고 독립 검토·문서 영향 검토·저작 보고서를 남긴다.
