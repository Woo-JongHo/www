# 검토 지적 수정과 통합 검증 및 게시

## 요청과 목적

고정 사본의 Terra·Opus 검토를 실제 현재 소스에 대조해 결함과 증거 부족을 수정하고, 재검증·문서·용도별 commit/push 이력을 남긴다. 과거 봉인 사본은 보존한다.

사용자의 직접 요청으로 접수했다. 요청 식별값은 work.json의 workflow.requestHash에 보존한다.

## 범위

변경 경로·표면·검증 명령과 커밋·게시 권한은 work.json의 workflow.authorization을 따른다. 범위 확대는 기존 권한으로 간주하지 않는다.

## 수용 기준

정의와 필수 여부의 정본은 work.json이다. 관련 기준: `FIX-1`, `FIX-2`, `FIX-3`, `FIX-4`, `FIX-5`.

## 결정과 열린 질문

작업 접수는 구현 완료가 아니다. 재개 시 같은 UUID와 현재 증거를 확인한다.

2026-11-15 게시 범위 확인에서 사용자는 “관련 구조도 변경도 포함하고 목적별로 커밋”을 선택했다. 이미 스테이징된 Ecosystem/004 명세와 관련 Ecosystem/004·005 변경을 이번 게시 범위에 포함한다. 이 선택은 미완료 기준을 완료로 바꾸거나 서로 다른 목적을 한 커밋에 묶는 승인이 아니다. 검증 후 후보별 커밋·push와 원격 ref를 기록한다.
