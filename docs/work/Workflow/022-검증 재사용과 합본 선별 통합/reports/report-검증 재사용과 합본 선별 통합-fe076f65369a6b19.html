시작점

v5 시도는 Native src/test 후속 변경으로 현행 증거가 아니었다.

접근과 결과

v6 동일 프로세스에서 exact Nodefocused 요청 2회·실제 실행 1회·재사용 1회가 당시 통과했으나 후속 공식 readback에서는 observed_environment_changed로 현재 적용 불가다. 통합 기준의 공통·GUI 관측은 별도이며 정식 기준 전체 수행으로 승격하지 않았다.

확인하지 못한 범위
