# 실행 단위

- AC-1: 저작/자동 Align 분기를 정본 스킬과 사용자 계약에 반영하고 생성 plugin·스킬 형식·실제 host 경로를 검증한다.
- AC-2: 실제 AST의 slash 역할을 보존 검사에 전달하고 정규식 내부 변경·ASI·주석·고정점 반례를 유지한다.
- AC-3: 동시 이관 완료 뒤 최종 inventory를 고정하고 지원 파일의 BoxBox source 검사와 직접 검토, 타입·테스트·빌드를 수행한다.
- AC-4: 실제 source·기준·정책에 묶인 읽기 전용 Opus 검토와 최종 diff를 확인한 뒤 commit·push·원격 ref를 확인한다.

- AC-5: 라이브러리의 201개 고정 원문·186개 번역 대상과 법문/기계 설정 보존을 확인하고 누락·오역·링크·고지·최종 inventory를 보완한 뒤 실제 검사기를 통과한다.

현재 단계: build. 미완료 항목을 완료로 표시하거나 검사 실패를 건너뛰지 않는다.
