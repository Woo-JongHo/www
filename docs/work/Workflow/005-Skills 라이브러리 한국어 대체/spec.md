# Skills 라이브러리 한국어 대체

## 요청과 목적

사용자는 보관용 영어 문서와 별도 한국어판을 함께 두지 않고 기존 Skills 라이브러리 문서를 한국어로 대체하기로 명시했다. 라이선스·저작권 고지와 코드·명령·식별자는 유지하고 원문 커밋·해시와 번역본 해시를 구분한다. 전체 번역과 공개 범위 검증 후 포함 변경·검증 결과·커밋 메시지를 먼저 사용자에게 제출하며, 검사 전 commit·push 권한은 없다. 기존 Chat·개발 역할의 병행 변경은 이 작업의 게시 범위로 합치지 않는다.

사용자의 직접 요청으로 접수했다. 요청 식별값은 work.json의 workflow.requestHash에 보존한다.

## 범위

변경 경로·표면·검증 명령과 커밋·게시 권한은 work.json의 workflow.authorization을 따른다. 범위 확대는 기존 권한으로 간주하지 않는다.

포함하는 작업은 다음과 같다.

- 7개 고정 출처의 선택 스냅샷에서 Markdown 168개, 에이전트 UI YAML 9개, 절 manifest JSON 9개의 자연어를 기존 경로에서 한국어로 대체한다.
- 코드·명령·기술 식별자와 법문·저작권 고지를 보존한다. 원문과 로컬 파일의 SHA-256·바이트 수를 별도 필드로 기록하며 원문과 다른 번역본을 원본 보존본으로 표시하지 않는다.
- gstack의 NOTICE가 가리키는 누락 법문 6개를 보완한다. 전체 선택 파일은 195개에서 201개가 되며, 이 수에는 제어용 `sources.json`·`inventory.json`은 포함하지 않는다.
- 실제 라이선스, 경로·해시·추가 파일·한국어 표기·수정 고지를 확인하는 검증기와 회귀 검사, 정제한 검증 기록과 커밋 준비 요약을 작성한다.
- 새 정적 디렉터리가 기존 전체 디렉터리 복사 방식의 Electron 패키징에 섞이지 않도록 라이브러리와 전용 검증기를 배포 제외 목록에 넣고 실제 복사 결과를 확인한다.

제품 실행·빌드·Chat은 이 연구 자료를 소비하지 않는다. 업스트림 스크립트·훅·바이너리 실행, 런타임 설치, 전역 설정 변경, 자동 스킬 주입은 제외한다. 병행 중인 Chat·개발 역할 변경, 비밀·원본 대화·로컬 증거·임시 스크립트·생성물은 게시 후보에 합치지 않는다.

## 수용 기준

정의와 필수 여부의 정본은 work.json이다. 관련 기준: `AC-1`, `AC-2`, `AC-3`, `AC-4`.

## 결정과 열린 질문

- 한국어 대체는 사용자가 선택한 방식이다. 공개 라이브러리에 별도 영어 읽기판을 추가하지 않는다.
- Feature Dev의 법문은 Apache-2.0이다. 나머지 여섯 출처의 주 라이선스는 MIT이며 gstack의 NOTICE와 제3자 법문을 함께 보존한다. 기존의 일괄 MIT 설명을 정정한다.
- 현재 제품·구조·기능 요구의 정본은 이미 존재하는 `docs/PRODUCT.md`, `docs/ARCHITECTURE.md`, `docs/specs/chat.md`다. Electron + TypeScript 선택은 제품 기준을 따르며 Tauri 비교 기록을 유지할 제품 대안으로 승격하지 않는다. 이 번역 작업에서 같은 상위 명세를 중복 생성하지 않는다.
- `CHANGELOG.md`는 정식 버전 배포별 사용자 영향 요약이 필요할 때 도입하는 것이 적절하다. 현재는 새 파일을 만들지 않고 작업별 배경·당시 결정·실행 검증 기록을 유지한다. 상위 정본 문서나 향후 변경 이력이 상세 작업 기록을 대체하지 않는다.
- 사용자 검사 전에 stage·commit·push하지 않는다. 준비 요약에는 정확한 포함·제외 범위와 실제 검증·미검증 한계를 함께 제시한다.

작업 접수와 실행기의 파일 작성 종료는 구현 수용이 아니다. 재개 시 같은 UUID와 현재 증거를 확인하며, 전체 번역 검수와 필수 독립 검토 전에는 완료로 표시하지 않는다.

## 2026-11-12 게시 범위 승인 갱신

2026-11-12T06:57:01.379Z에 통합 담당 root가 전달한 사용자 명시 응답은 “라이브러리도 보완해 전체 게시”다. 기존의 번역 보완과 별도 사용자 검사 전 게시 보류 기록은 당시 결정으로 보존한다. 현재 요청에서는 라이브러리 미완료 보완과 전체 변경의 BoxBox 검증 후 commit·push를 허용하며 실제 게시 통합은 root가 소유한다. 이 승인은 미완료 번역을 완료로 간주하거나 독립 검토·필수 검증을 생략하는 권한이 아니다.

자료는 계속 정적 연구 목록이며 실행·설치·신뢰된 스킬 활성화 대상으로 전환하지 않는다. 원문201개 지문은 선택된 고정 Git commit의 blob으로 입증하고, 법문·고지14개와 원문 기계설정1개는 바꾸지 않는다.
