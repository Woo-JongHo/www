# 개발 환경 사전점검과 실행 증거 보존

## 요청과 목적

실제 실행에서 관측한 PATH 손실, Git 이력과 index 없는 격리 검증, 저장소 안 설치물, 출력 절단을 모델 시작 전에 분류하고 증거를 보존한다. 개인 경로와 기밀 원문은 작업 문서나 공개 이슈에 기록하지 않는다.

사용자의 직접 요청으로 접수했다. 요청 식별값은 work.json의 workflow.requestHash에 보존한다.

## 범위

변경 경로·표면·검증 명령과 커밋·게시 권한은 work.json의 workflow.authorization을 따른다. 범위 확대는 기존 권한으로 간주하지 않는다.

## 수용 기준

정의와 필수 여부의 정본은 work.json이다. 관련 기준: `ENV1`, `ENV2`, `ENV3`, `ENV4`.

## 결정과 열린 질문

작업 접수는 구현 완료가 아니다. 재개 시 같은 UUID와 현재 증거를 확인한다.

## 이슈와 제외 범위

공개 이슈: https://github.com/Woo-JongHo/www/issues/1 . 전역 설치·인증·trust 설정 변경과 재설치는 제외한다. 기록된 과거 usage는 실제 관측된 부분합이며 금액이나 전체 사용량으로 추정하지 않는다.

## 커밋·게시 권한 근거

사용자 원문 “이 세션에서 작업한 것들은 커밋 푸시 기록 전부다 남기고 진행”과 이 환경 문제 해결 요청을 연결한다. 목적별 후보 검증 뒤 통합 담당 부모만 commit·push를 수행하며 격리 저자는 실행하지 않는다.
