용도와 역할별 커밋 후보 분리

다음 작업부터 용도·역할별 커밋 후보를 먼저 나누고 하나씩 실행하도록 환경에 반영했다.

전체 변경을 저장소별 한 커밋으로 묶어 목적별 검토와 선택적 되돌리기가 어려웠다. 전역 정본 포인터도 낡은 위치를 가리켰다. 전역 정본 경로와 분리 기준 연결, WWW 커밋 스킬, 준비 양식을 수정했다. 후보별 목적·경로·검증·의존 순서와 순차 stage·commit을 요구한다.

기록된 변경

  • 머신 전역 지침은 정본의 후보 분리 기준으로 연결하고 실제 WWW 경로를 사용한다.
  • 전체 범위 승인을 단일 커밋 지시로 해석하지 않으며 관련 구현·테스트·문서는 함께 둘 수 있다.
  • 기존 승인 승계와 필요한 검증 재사용을 유지한다.

요구와 결과

구조화된 요구·결과 설명이 없어 저장된 수용 기준과 당시 상태를 그대로 보여 줍니다.

기록에 남은 주요 선택

  • 기존 게시 커밋은 유지하고 이번 환경 변경에서는 stage·commit·push를 실행하지 않는다.
  • 의미 분류를 파일 수나 디렉터리 기반 Git hook으로 강제하지 않고 에이전트 절차로 적용한다.
