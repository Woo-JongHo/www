# 코드 기반 아키텍처 설계도와 계층형 Node 그래프

## 요청과 목적

코드 기반 아키텍처 설계도와 계층형 Node 그래프

사용자의 직접 요청으로 접수했다. 요청 식별값은 work.json의 workflow.requestHash에 보존한다.

## 범위

변경 경로·표면·검증 명령과 커밋·게시 권한은 work.json의 workflow.authorization을 따른다. 범위 확대는 기존 권한으로 간주하지 않는다.

## 수용 기준

정의와 필수 여부의 정본은 work.json이다. 관련 기준: `AC-1`, `AC-2`, `AC-3`, `AC-4`, `AC-5`.

## 결정과 열린 질문

사용자는 계층별 그룹과 정돈된 방향 연결선을 가진 아키텍처 설계도를 선택했다. 현재 코드를 근거로 한 설계 문서와 실제 앱의 Node 그래프를 함께 만든다. 다른 저장소나 선택 폴더의 범용 분석까지 확대하지 않는다.

현재 실행 호스트는 AC 전원의 Mac mini이고 자동 시스템 잠자기 설정은 0이다. 노트북의 원격 접속과 분리된 tmux 세션에서 저작과 검사를 수행한다. Mac mini 종료·재부팅 후 자동 재시작까지 약속하지 않는다.

기존 main 브랜치에는 Chat 활동 사이드바 변경이 있다. 해당 변경을 보존하고 그래프와 직접 관련된 부분만 추가한다. commit·push·배포는 요청하지 않았다.

## 관찰 시나리오

생태계를 열면 실제 코드 모듈을 계층별로 묶은 설계도가 먼저 나온다. 개요에서 연결 방향을 읽고 노드를 선택해 역할·근거 파일·의존 관계를 확인한다. 파일명 검색과 계층 필터로 관심 범위를 좁히고 전체 보기로 돌아간다. 이전 생태계 안내는 별도 보기로 남겨 개발 절차와 미래 방향을 코드 import 관계와 혼동하지 않게 한다.

구현된 동작만 현재 제공 기능으로 설명한다. 코드 분석으로 입증되지 않은 IPC·JSON-RPC 실행 흐름을 import 간선으로 위장하지 않는다. 자동 추출 범위와 명시한 의미 관계를 화면과 설계 문서에 구분한다.
