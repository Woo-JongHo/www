# 구현과 검증 단위

## 통합 3회차의 인계

새 제품 수정·모델 호출·GUI 재실행 없이 현재 소스와 공식 증거를 대조했다. 최신 architecture 시도 `attempt-e48507b1-53c8-4a1f-8799-fd436232e0b1`와 `.www/evidence/architecture-u9TzmT/`의 네 화면은 현재 입력에 적용된다. 생성기의 `--check`도 현재 snapshot 일치를 확인했다. 직접 검색 결과와 시각 QA·검토 한계는 verification.md의 `integration-3`에 연결한다.

남은 실행은 2회차와 동일하다. 호스트의 공식 수정 build → 바뀐 입력에 대한 공식 verify(전체 check와 architecture·ecosystem·Chat 순차 GUI) → 인증 복구 후 공식 review → 통합 보고·완료 판정이다. 과거 입력의 ecosystem 성공이나 현재 architecture 성공으로 AC-4 전체를 수용하지 않는다. 최종 통합 회수에서도 차단이 해결되지 않아 완료를 기록하지 않는다.

## 통합 2회차의 현재 다음 행동

확장 입력의 외부 architecture 시도 `attempt-181b7f09-a94c-46ff-b3ac-cbd8478d9643`는 유효하며 스크린샷 네 장을 직접 읽었다. 같은 소스·같은 입력의 집중 검사와 분리 실행 근거는 재사용했다. 최신 외부 check·ecosystem의 Bun 탐색 실패를 숨기지 않았고, Bun PATH를 명시한 공식 check 시도 `attempt-0cba5a1f-5ef9-4728-bbe9-1a6104d90317`는 통과했다.

남은 순서는 호스트의 공식 build 실패 수정, 명시한 PATH에서 현재 소스의 ecosystem·Chat 및 변경으로 무효화된 검사만 재실행, 인증 복구 후 읽기 전용 Opus 검토, 통합 보고·완료 판정이다. 실행 중인 기존 호스트 루프는 수정 하네스를 자동 실행하지 않으며 Chat 검사도 포함하지 않으므로 기존 세 명령만 반복하는 것으로 수용되지 않는다. 같은 EPERM·인증 실패의 반복 호출과 통합자의 하네스 밖 제품 저작은 하지 않았다. 업무 상태는 완료가 아니다.

## 통합 1회차의 실패 수정과 재검증

공식 build 수정 대상은 design.md의 통합 1회차 절을 따른다. 실제 작성 대상은 architecture 모델·분석기·화면·검증 도구·집중 테스트·생성 JSON이며, renderer는 기존 Chat/sidebar 동작을 보존하는 작은 구조 변경만 허용한다. 선언한 writes 밖의 제품 변경은 하지 않는다. 하네스가 전달한 guide/check를 읽고 구조적 간결화로 해결 가능한지 판단하며 미해결을 성공으로 보고하지 않는다.

통합 책임자는 최종 BoxBox·타입·집중 검사와 공식 verify 시도를 연결한다. 호스트는 Bun PATH를 보완한 뒤 같은 dist를 순차 사용해 architecture·ecosystem·Chat을 검증하고 정책의 읽기 전용 Opus 검토를 실행한다. 입력 확대와 소스 수정으로 첫 외부 근거는 현재 완료 증거가 아니다. 통합 종료 시 재호스트 요청과 남은 차단을 파일·저작 보고서에 남긴다.

1. 실제 코드 분석과 결정적 snapshot, 파일/행 근거 및 집중 검사(AC-1).
2. 계층별 설계도·노드 상세·검색·필터·조작 및 보조 생태계 보기(AC-2·AC-3).
3. 빌드 배선·현행 명세·코드 설계도 문서 및 실제 Electron 시나리오(AC-4).
4. 부모의 하네스 영수증, 분리 세션 확인, 증거 연결·독립 검토·저작 보고서(AC-5).

## 구현 자식 실행의 인계

제품 구현과 문서 변경을 반영했다. 기본 화면은 코드 기반 계층 개요이며 기존 안내는 별도 보기로 보존했다. 생성 자료는 현재 47개 모듈·105개 참조를 포함한다. 실행 결과·소스 식별·미해결과 부모의 다음 명령은 [구현 인계](implementation.md)에 정리했다.

`npm run check`는 통과했지만 BoxBox 미해결, 실제 Electron 검증, 독립 검토와 업무 수용은 남아 있다. 부모 실행부가 같은 UUID로 검증·검토·보고서를 연결한다. 작업을 done으로 바꾸지 않았다.
