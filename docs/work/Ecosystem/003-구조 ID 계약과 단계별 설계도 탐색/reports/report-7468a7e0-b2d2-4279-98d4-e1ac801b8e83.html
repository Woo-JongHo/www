구조 ID 계약과 단계별 설계도 탐색

생태계 사이드바에 단계별 구조 지도와 명세·코드·검증 ID 연결을 구현했고, 현재 전체 검사와 실제 화면 검증을 통과했습니다. 추가 BoxBox 범위와 최종 독립 검토는 남아 있습니다.

전체 구조를 파악하고 클릭할수록 세부를 읽는 지도가 목표였습니다. 구조 ID를 정본에 두고 명세와 코드가 같은 ID를 선언하도록 연결했습니다. 생태계 사이드바는 이 정본에서 생성한 지도를 보여 주며 별도의 수동 지도를 유지하지 않습니다. 현재 전체 검사와 실제 Electron 탐색은 통과했지만, 추가 BoxBox 승인과 최종 독립 검토가 남아 있어 업무 완료로 표시하지 않습니다.

중요한 선택과 그 이유

명세와 지도에 별도 ID를 중복 보관할 것인가

선택 정본 책임 ID와 명시 선언을 검사한 뒤 지도를 생성합니다.

판단 근거 파일 위치와 책임의 수명이 다르고 별도 수동 지도는 코드와 갈라질 수 있습니다.

  • 파일 import 지도만 사용

감수한 점 새 관리 대상 소스에는 선언과 정확 의존 등록이 필요합니다.
