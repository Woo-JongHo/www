# 구현 단위와 검증

## 지도와 책임 탐색

- MAP-READ: 구성·의존 보기, 선택 범위 강조, 방향별 포트·통로, 간선 번호와 목록을 구현했다. 실제 화면 검사와 독립 검토 결과는 verification.md와 work.json에서 판정한다.
- MAP-NODE: 부모·하위 360×112px 규격, 역할 요약·구성 수, 최대 세 열·내부 스크롤을 구현했다.
- MAP-DETAIL: 정본 역할 설명을 갱신하고 하위 포함 근거 집계·구성별 탐색·담당 코드·방향별 참조 그룹을 연결했다. 직접 명세/구현/검증 근거는 접힘 영역에 보존했다.
- MAP-FLOW: 기존 검색·단계별 이동·키보드·상세 닫기·줌·팬·채팅 보존 검사에 새 UI 시나리오를 연결했다.

## 검증 중 발견

첫 GUI 검사에서 새 SVG title 때문에 기존 :first-child 노드 표면 selector가 적용되지 않는 것을 캡처로 확인해 rect selector를 수정했다. 기존 GUI probe의 외부 참조 ID 읽기는 새 그룹 버튼의 data-target-id를 사용하도록 갱신했다. 일반 5초 예산의 canonical fixture가 병행 실행에서 시간 초과되어 원문을 보존하고 공식 실도구 검사 예산인 60초로 재검사한다. 테스트를 생략하거나 실패를 통과로 옮기지 않는다.

## 변경 보존

작업 도중 별도 Chat/004 검증 기록과 Workflow/013 작업 및 목차 변경을 관측했다. 이 작업의 변경으로 분류하거나 되돌리지 않는다. index의 본 작업 항목만 추가했다. 커밋·push는 수행하지 않는다.
