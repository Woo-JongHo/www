사람이 읽는 구조 지도와 책임 설명

생태계를 사람이 구조를 파악하고 관리하는 지도이자 설계도면으로 개선했다. 포함 관계와 코드 의존 관계를 나누고 부모·하위 노드를 같은 규격으로 맞췄다. 대화 세션을 선택하면 역할과 세 하위 구성, 담당 파일 및 참조 방향을 확인할 수 있다. 안정된 최종 소스의 집중 검사·실제 Electron 검사·통합 검사와 Opus 읽기 전용 독립 검토가 통과했다.

계층선과 import 선을 동시에 그렸고 방향별 포트를 공유했다. 부모·하위 노드의 높이와 정보가 달랐으며 대화 세션의 설명은 제목을 반복하고 하위 구성과 담당 코드를 함께 읽기 어려웠다. 내부 구성과 코드 의존 보기를 전환하고 책임별 참조를 좁힐 수 있다. 360×112px 노드를 최대 세 열로 배치하며, 역할·하위 구성·담당 코드·들어오는/나가는 실제 참조와 원문 근거를 읽고 이동한다.
