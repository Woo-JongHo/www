# 생태계 지도 설계

현재 Electron 앱의 3열 구조와 어두운 색상 토큰을 유지한다. 생태계 선택 시 가운데는 그래프, 오른쪽은 상세 설명이다. 앱 실행(파랑 #8ab4ff), 개발 절차(보라 #b8a5ed), 기록과 검토(청록 #69c6b2), 후속 방향(회갈색 #b4a382)을 수평 영역으로 구분한다. 배경 #0b0b0c, 표면 #111113, 경계 #29292e를 재사용한다. 시스템 한글 서체로 제목과 설명을 읽고 파일 경로만 고정폭으로 표시한다.

계층을 장식 카드로 나누는 대신 연결선을 주된 탐색 대상으로 삼는다. 근거 경로를 가진 정적 TypeScript 모델이 방향 관계와 설명을 소유하며 별도 IPC·서버·패키지 의존성은 추가하지 않는다. SVG 노드는 Tab, Enter, Space로 선택할 수 있다. 검색과 영역 필터는 전체 맥락을 남기고 일치하지 않는 노드를 흐리게 한다. 결과 목록과 상세 관계 버튼은 해당 노드로 이동한다.

대화 DOM은 숨긴 채 유지해 입력·초점 대상·스크롤과 실행 구독을 보존한다. 생태계 상태는 화면 재진입 시 초기화한다. 지도는 실시간 실행 상태나 서버 색인이 아니며 미구현 방향과 연결은 점선과 문구로 구분한다.

AC-1은 실제 Electron에서 초안과 전환을 확인한다. AC-2는 모델의 실제 경로·방향·후속 연결 검사로 확인한다. AC-3은 Electron에서 노드·검색·필터·배율·키보드 탐색을 확인한다. AC-4는 집중 테스트·타입 검사·번들과 기존 합성 대화 probe로 확인한다.
