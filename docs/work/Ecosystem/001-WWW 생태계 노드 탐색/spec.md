# WWW 생태계 노드 탐색

## 요청과 목적

WWW 생태계 노드 탐색

사용자의 직접 요청으로 접수했다. 요청 식별값은 work.json의 workflow.requestHash에 보존한다.

## 범위

변경 경로·표면·검증 명령과 커밋·게시 권한은 work.json의 workflow.authorization을 따른다. 범위 확대는 기존 권한으로 간주하지 않는다.

## 수용 기준

정의와 필수 여부의 정본은 work.json이다. 관련 기준: `AC-1`, `AC-2`, `AC-3`, `AC-4`.

## 결정과 열린 질문

작업 접수는 구현 완료가 아니다. 재개 시 같은 UUID와 현재 증거를 확인한다.

## 관찰 시나리오와 제외 범위

대화 초안을 둔 채 지도를 열고 노드를 선택한다. 파일 경로 검색과 영역 필터를 조합하고 전체 보기로 복귀한다. 대화로 돌아와 초안·명령 펼침·읽기 위치를 확인한다. 개발 역할과 Native를 구분하고 각 관계의 방향·근거를 읽는다.

실시간 소스 분석, 선택 폴더 지도, 서버 API·Canvas 편집, 기존 진행 중 대화의 재시작, 자동 커밋·게시는 포함하지 않는다. 현재 App의 레이아웃을 관찰하고 같은 3열 구조를 활용했다.
