# 작업 종료 보고서와 앱 리포트

## 요청과 목적

작업 종료 보고서와 앱 리포트

사용자의 직접 요청으로 접수했다. 요청 식별값은 work.json의 workflow.requestHash에 보존한다.

## 범위

변경 경로·표면·검증 명령과 커밋·게시 권한은 work.json의 workflow.authorization을 따른다. 범위 확대는 기존 권한으로 간주하지 않는다.

## 수용 기준

정의와 필수 여부의 정본은 work.json이다. 관련 기준: `AC-1`, `AC-2`, `AC-3`, `AC-4`, `AC-5`.

## 결정과 열린 질문

작업 접수는 구현 완료가 아니다. 재개 시 같은 UUID와 현재 증거를 확인한다.

## 추가 직접 요청

사용자는 “네이티브 답변이 끝나고, LLM이 판단했을 때 리포트가 필요한 정도의 규모라면 리포트를 자동으로 생성하는 하네스”를 요청했다. AC-6과 REPORTS-5로 추가하며 기존 기준을 약화하지 않는다. 앱 Native 종료 경로가 대상이고 모든 외부 호스트에 전역 훅을 설치하지 않는다.
