# 독자의 판단을 돕는 보고서 양식

## 요청과 목적

독자의 판단을 돕는 보고서 양식

사용자의 직접 요청으로 접수했다. 요청 식별값은 work.json의 workflow.requestHash에 보존한다.

## 범위

변경 경로·표면·검증 명령과 커밋·게시 권한은 work.json의 workflow.authorization을 따른다. 범위 확대는 기존 권한으로 간주하지 않는다.

## 수용 기준

정의와 필수 여부의 정본은 work.json이다. 관련 기준: `AC-1`, `AC-2`, `AC-3`, `AC-4`, `AC-5`, `AC-6`.

## 결정과 열린 질문

작업 접수는 구현 완료가 아니다. 재개 시 같은 UUID와 현재 증거를 확인한다.


## 적용 기준

사용자가 제시한 상세 평가는 코드 사실의 증거가 아니라 새 양식의 요구와 검토 기준으로 사용한다. 필수는 결론·요구와 결과·검증 대상과 방법·관측과 한계이며 주요 선택은 실제 선택이 있을 때만 쓴다. 상단 prose, 상태 시점 일관성, 메타데이터 상세화가 핵심이다. 원본 보고서에 없던 사실을 뒤늦게 추가하지 않는다.
