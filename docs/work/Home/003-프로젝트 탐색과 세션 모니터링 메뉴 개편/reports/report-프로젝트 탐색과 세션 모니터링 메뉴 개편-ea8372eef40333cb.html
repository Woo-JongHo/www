프로젝트 탐색과 세션 모니터링 메뉴 개편

프로젝트 목록 탐색 중 중앙 화면 유지와 다섯 공통 메뉴·현재 대화 탭의 세션 모니터링을 Home003의 명세·설계·실행 계획으로 정리했다. 제품 코드는 변경하지 않았다. 문서 계약과 기준별 연결은 확인했으며 별도 Claude Sonnet 5 의미 검토는 180초 응답 시간 초과로 미실행 상태다.

목록을 살펴보는 동안 하던 작업이 사라지는 불편을 줄이기 위해 탐색과 중앙 화면을 분리하는 다음 구현 기준을 작성했다. 사용자가 정한 다섯 메뉴와 세션 모니터링 범위를 명세·설계·실행 계획에 연결했다. 문서 구조와 기준 연결은 확인했지만 앱은 변경하지 않았으며 별도 의미 검토의 응답은 받지 못했다.
