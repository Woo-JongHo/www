# 업무 진입점과 탐색 구조 연구

## 요청과 목적

Figma·VS Code·Linear의 공식 근거와 현재 WWW 코드를 조사해 업무 진입점과 탐색 구조의 연구 제안을 작성한다. 제품 구현과 GUI 검증은 이번 범위에 포함하지 않는다.

사용자의 직접 요청으로 접수했다. 요청 식별값은 work.json의 workflow.requestHash에 보존한다.

## 범위

변경 경로·표면·검증 명령과 커밋·게시 권한은 work.json의 workflow.authorization을 따른다. 범위 확대는 기존 권한으로 간주하지 않는다.

## 수용 기준

정의와 필수 여부의 정본은 work.json이다. 관련 기준: `R1`, `R2`, `R3`.

## 결정과 열린 질문

연구 본문은 [업무 진입점과 탐색 구조 연구](research.md)다. 공식 원문의 관측 사실, WWW 적용 제안, 비용과 시험 계획을 구분한다. 단일 사이드바의 확장/축소와 오늘 중심 홈은 권고안이며 사용자에게 확정된 결정이나 구현된 제품 동작으로 표현하지 않는다.

이번 변경은 연구 문서와 기록에 한정한다. 실제 앱·시제품 구현, 외부 캘린더 연결, 다중 기기 동기화와 커밋·게시를 포함하지 않는다. 개인 업무를 직접 등록하고 기존 작업을 참조하는 혼합형을 작업 가정으로 사용한다.

독립 감사와 실제 검증 결과는 [검증 기록](verification.md)에 구분한다. 작업 접수와 문서 구조 검사는 제품 구현 완료가 아니다. 재개 시 같은 UUID와 현재 증거를 확인한다.
