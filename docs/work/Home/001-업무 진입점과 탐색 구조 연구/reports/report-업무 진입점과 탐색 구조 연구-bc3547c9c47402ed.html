업무 진입점과 탐색 구조 연구

개인 업무관리 진입점과 탐색 구조를 위해 Figma·VS Code·Linear 공식 문서 및 현재 WWW 코드를 연구했다. 기본은 이름 있는 단일 사이드바, 축소하면 아이콘 바, 중앙은 오늘 업무, 오른쪽은 필요한 상세를 권고한다. 공식 근거와 적용 추론·비용·시험 계획을 분리했다. Opus 독립 감사는 CLI 로그인 실패로 미실행이며 제품 구현과 사용성 검증은 하지 않았다.

앞선 대화에는 아이콘 레일과 탐색 패널을 상시 나란히 두는 초기 구상만 있었고 패턴 결합 비용과 화면별 전환 경계가 충분히 정리되지 않았다. research.md에 공식 출처 14개, 기존 코드 근거, 대안 비교, 업무·일정 의미, 패널·포커스·너비·전환·실패 규칙과 대표 사용자 여정을 정리했다. 제품 코드는 변경하지 않았다.

기록된 변경

  • 연구 본문과 최소 접수 명세·작업 원장을 추가하고 작업 목차에 연결했다.
  • 현행 제품·구조·디자인 요구를 읽고 연구 제안과 제공 기능을 구별했다.
  • 실제 형식 검사와 Opus 감사 미실행 영수증을 verification.md에 남겼다.

요구와 결과

구조화된 요구·결과 설명이 없어 저장된 수용 기준과 당시 상태를 그대로 보여 줍니다.

공식 원문을 열어 확인한 제품별 패턴과 출처, 관측 사실과 WWW 적용 추론을 분리한다.

기록에 남은 주요 선택

  • 기본 탐색은 이름 있는 단일 사이드바로 권고하고 축소 시 아이콘 바로 전환한다. 상시 두 탐색 열의 폭 비용을 줄이되 발견 가능성을 유지하려는 선택이다.
  • 업무 상세 확인과 실제 Native 프로젝트 전환을 분리하고 기존 실행·승인 제약을 유지한다.
  • 외부 연동과 자유 도킹보다 작업 맥락 보존·정확한 완료 의미·실패 복구를 우선한다.

무엇을 어떻게 확인했나요

당시 관측과 현재 적용성은 다릅니다. 발행 당시 기록입니다. 이 HTML 사본은 현재 파일 상태를 조회하지 않습니다.

구체적인 검증 대상·방법·기대·관측 설명이 기록되지 않았습니다. 명령이나 종료 코드만으로 사용자 행동을 확인했다고 추정하지 않습니다.

연결된 검사 시도가 없습니다. 미검증입니다.

독립 검토

독립 검토: 미실행으로 기록 · 관측 모델 미확인.

확인하지 못한 범위

  • Opus CLI가 Not logged in 오류로 종료되어 실제 모델이 관측되지 않았다. 독립 감사 통과를 주장하지 않고 다른 모델로 대체하지 않았다.
  • 참고 제품 직접 조작·WWW GUI·파일럿 사용성 시험은 실행하지 않았다. 너비와 전환 규칙은 실측 전 권고안이다.
  • 문서 형식 검사 통과는 연구의 최종 감사나 제품 완성도 증명이 아니다. 원장의 필수 기준은 자동 통과 처리하지 않았다.

남은 일과 해소 행동

  • Opus 인증 복구 뒤 같은 연구 입력에 독립 감사를 실행한다.
  • 구현 파일럿에서 홈→업무 상세→대화→복귀와 실행 중 승인 도착을 먼저 확인한다.

담당·해소 조건·영향은 별도로 기록되지 않았습니다.
