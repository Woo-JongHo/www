# 실행 계획

1. DOC-BYTES: 원문 백업과 SHA 고정 후 같은 bytes로 이동한다.
2. DOC-FIND: 목차 링크와 이전 빈 작업 디렉터리를 정리한다.
3. DOC-CONTRACT: 정확 bytes/경로 검사와 전체 check-workflow를 실행한다.
4. 문서 영향 검토·독립 Opus·공식 보고서·현재 readback 후 완료 여부를 판정한다.

이 절은 구현 시작 시점의 계획이다. 실제 현재 단계는 아래 인계를 따른다. 원격·제품 코드 변경은 없다.

## 현재 인계

원문 bytes 이동과 목차 링크 작성, 두 공식 검증 시도, 문서 영향 검토·실제 Opus 감사·공식 보고서·complete core 재조회를 완료했다. 세 기준과 감사가 현재 적용 가능하며 status=done이다. 이 작업에 남은 검사는 없다. W020의 스킬 행동 검증은 별도 UUID에서 이어간다.
