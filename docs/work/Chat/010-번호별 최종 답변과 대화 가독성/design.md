# 설계

기존 Native 요청 구성에서 진행·최종 답변 지침을 구분해 조합한다. 결과를 먼저 말하고 실제 의미 단위로 번호·제목·설명을 작성하게 하며 사용자 명시 형식과 짧은 질문을 존중한다. 새 스레드와 재개는 같은 지침을 전달한다. 설치된 codex generate-ts의 ThreadResumeParams.developerInstructions 지원을 확인했으며 재개에 모델·승인·sandbox는 추가하지 않는다.

화면은 기존 React Markdown의 의미상 ol/li를 유지한다. 기존 팔레트의 본문/보조 대비, 76ch 읽기 폭, 14px 본문과 1.85 행간, 항목 사이 여백과 번호 강조로 위계를 만든다. 내용 추출·재작성·추가 LLM 요약·가짜 번호는 사용하지 않는다. 실행 집계는 기본 접힌 native details로 낮추고 실패·미확인·중단은 기본 펼침이다.

실패 위험은 구형 대화의 지침 누락, 사용자 수동 펼침 초기화, 좁은 창 overflow, 긴 응답의 읽기 위치 변화와 모델의 과장이다. 단위 검사·실제 Electron CDP·실제 Native 제한된 응답 시나리오를 구분한다. 보고서 흐름·권한·원문 저장·다른 작업 파일은 유지한다.
