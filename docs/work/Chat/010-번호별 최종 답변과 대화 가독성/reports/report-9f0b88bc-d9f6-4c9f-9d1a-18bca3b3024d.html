확인하지 못한 범위

  • 실제 Native 검사는 제공된 사실을 읽기 전용·승인 never·도구 금지 조건에서 정리한 응답 검사다. 제품 기본 권한 그대로 기능을 수행한 증거는 아니다.
  • 모델이 모든 응답에서 같은 형식을 따른다고 보장하지 않는다. 실제 세 시나리오는 기능 결과·재개 후 부분 실패·숫자만 답하기를 확인했다.
  • 일부 실패/중단 GUI 조건은 상태 문구를 검사하며 모든 상태의 open 속성을 직접 검사하지 않는다. 기본 펼침 조건은 소스 검토와 실패 화면 캡처로 확인했다.
