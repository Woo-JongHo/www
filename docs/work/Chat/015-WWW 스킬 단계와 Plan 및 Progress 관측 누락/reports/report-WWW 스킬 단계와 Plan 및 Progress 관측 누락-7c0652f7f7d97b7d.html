WWW 스킬 단계와 Plan 및 Progress 관측 누락

WWW 스킬 단계와 Plan·Progress의 관측 누락을 Chat015 버그로 명세화하고 GitHub #2에 bug 이슈로 등록했다. 실제 투영 함수의 합성 입력에서 Plan 없는 공개 설명의 누락과 미관측 다섯 항목의 대기 표시를 확인했다. 제품 코드는 수정하지 않았다.

사용자가 작업 중인 스킬과 진행 상태가 보이지 않는다고 보고해 표시 조건을 조사했다. 현행 함수에 합성 사건을 넣자 공개 설명이 있어도 Plan이 없으면 Progress가 비고 미관측 항목 다섯 개가 대기로 표시됐다. 이 근거와 실제 세션에서 아직 모르는 부분을 분리해 다음 수정의 명세·진단·검증 계획을 작성하고 GitHub 버그로 등록했다.
