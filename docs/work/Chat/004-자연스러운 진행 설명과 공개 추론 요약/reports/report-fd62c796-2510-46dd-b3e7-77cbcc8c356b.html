자연스러운 진행 설명과 공개 추론 요약

채팅에 자연스러운 한국어 진행 설명 지침과 Native의 공개 추론 요약 표시를 구현했다. 고정 단계 라벨을 제거하고 중요한 발견·실패·방향 전환의 이유와 결과를 설명하도록 요청한다. 집중 테스트 86개·타입·소스 정책·빌드와 최종 합성 Electron 회귀, 실제 Native 표본 및 독립 Opus 감사를 수행했다. 기능 검사와 감사는 통과했지만 BoxBox 미해결로 전체 완료는 보류한다.

기존 채팅은 Native의 commentary를 출처 라벨과 함께 표시했고 reasoning 항목을 모두 제외해 공개 summary도 보이지 않았다. 진행 설명을 더 자세히 요청하는 앱 지침이 없었다. 새 앱의 새 스레드에는 자연스러운 한국어 진행 설명 지침을 추가하고 턴마다 detailed 공개 요약을 요청한다. 채팅은 제공된 summary와 commentary를 고정 가시 라벨 없이 본문으로 표시한다. 원문 reasoning·analysis는 제외하며 중복·턴 격리·완료·종료·절단을 처리한다.

다음 행동 미해결 BoxBox 형식과 기존 REFUSE의 처리 범위를 정해 정상 작성 검사 통과를 확보한 뒤 같은 UUID에서 재검증한다.

남은 차단 사항 기능 검사와 Opus 감사는 통과했으나 공식 저작 하네스의 BoxBox FIXABLE·REFUSE가 미해결이다. 미승인 형태의 정렬·formatter 우회 없이 보류한다.

기록된 변경

  • src/native-chat.ts의 params 구성을 실제 main RPC에 연결했다. 기존 cwd·승인·sandbox·사용자 입력은 보존한다.
  • projection에서 공개 summary를 문단별로 스트리밍하고 완료 snapshot으로 대체한다. raw textDelta와 content는 표시하지 않는다.
  • renderer에서 공개 설명의 가시 출처 라벨을 제거하고 접근성 이름은 보존했다.
  • 원문 미노출 검사를 유지하면서 활동 fixture의 공개·비공개 자료를 분리하고 실제 stdio 통합 검사를 추가했다.
  • Chat 명세·제품·구조·개발 안내와 같은 UUID의 명세·설계·검증 기록을 갱신했다.

  • 모델의 내부 원문 사고를 요청하지 않고 공개 요약과 작업상 이유·관찰·다음 행동만 요청했다.
