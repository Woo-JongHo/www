미검증으로 기록

미검증으로 기록

미검증으로 기록
단계·호출 자료가 없으면 미제공/누락을 표시한다. 대화 내용으로 호출·진행·성공을 추정해 만들지 않는다. 문서 읽기와 실제 실행도 구분한다.

미검증으로 기록

미검증으로 기록

미검증으로 기록

미검증으로 기록
