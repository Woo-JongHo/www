# 명령 카드 구조화 출력 가독성

## 요청과 목적

사용자는 기존 가독성 작업 후에도 긴 셸 명령과 한 줄 JSON이 단색으로 표시된다고 보고했고, 문서 작성·개발 설계·구현·검증을 요청했다. 기존 Chat 007의 공백 보존은 이미 있는 공백을 유지하는 기능이며 JSON 정렬이나 구문 강조는 제공하지 않았다. 이번 작업은 별도 UUID로 그 범위를 보완한다.

## 범위와 시나리오

종료된 명령의 완전한 JSON 객체·배열을 2칸 들여쓰기와 구문 색상으로 읽는다. 원문 전환과 복사는 수신 문자열을 그대로 사용한다. 셸 명령의 문자열·옵션에도 색상을 적용한다. 실행 중·절단·불완전·일반 로그는 원래 줄 경계를 유지한다. 정렬된 미리보기의 생략 수는 표시 줄 기준임을 밝힌다.

종료 코드 0인 외부 프로세스가 `verdict: not_run`인 검토 JSON을 출력하면 프로세스 종료와 출력의 검토 미실행을 각각 표시한다. 출력의 보고값이며 실제 검토 수용 여부를 대신하지 않는다. 임의 로그를 성공·실패로 추론하지 않는다.

원본 저장·투영·실행 권한·인증·검토 core·자동 보고서의 동작은 변경 범위 밖이다. commit·push 권한은 없다.

## 수용 기준

AC-01~04의 정의·결과는 work.json이 소유한다. 완전한 JSON·큰 정수·이스케이프·중복 키, 불완전/절단/실시간 출력, 원문 복사·키보드·좁은 창과 기존 펼침 동작을 검사한다.

## 결정

외부 강조 라이브러리 없이 제한된 JSON·셸 토큰을 React 텍스트 노드로 표시한다. 사용자 승인을 다시 요구할 미결정 사항은 없다. 필수 Opus 검토가 미실행이면 구현·검사 결과와 분리해 차단으로 남긴다.
