# 구현과 검증 단위

1. AC-01~03: 순수 표시 계산, 카드·스타일과 회귀 테스트를 구현한다.
2. AC-04: 기존 Electron 하네스의 이력과 검증 시나리오를 확장한다.
3. 소스 정책·타입·집중 테스트·빌드·Electron을 실행하고 현행 명세·구조·디자인 문서를 대조한다.
4. 공유 core의 Opus 읽기 전용 검토와 문서 영향 기록을 회수하고 저작 보고서를 발행한다. 미실행을 완료로 승격하지 않는다.

BoxBox project mode는 실제 조회에서 off였다. guide/source 검사는 비활성으로 기록하며 PASS로 주장하지 않는다. 현재 Codex 세션에서 직접 저작하며 별도 구현 모델 실행 하네스의 context 수용은 검증한 것으로 쓰지 않는다.
