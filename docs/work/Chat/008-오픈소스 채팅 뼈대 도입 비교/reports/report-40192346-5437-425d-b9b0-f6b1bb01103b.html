오픈소스 채팅 뼈대 도입 비교

현재 Chat 기능과 공개 오픈소스 뼈대를 비교했다. WWW 안의 채팅 뼈대 도입은 assistant-ui, 전체 앱 기반 교체는 T3 Code를 우선 후보로 제안한다.

현재 WWW에는 Native 실행·승인·중단·활동·보고서가 있으나 일반 텍스트 답변과 메모리 사건만 제공해 대화 저장·재열기가 부족하다. 현행 기능과 공백, 후보의 고정 SHA·라이선스·실제 코드 경계를 비교 문서에 기록했다. 제품 코드와 의존성은 그대로이며 도입 방식 선택과 실행 실험이 남아 있다.
