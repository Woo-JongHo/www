Native 대화 Bypass 기본값 적용

새 대화와 기존 대화 재개에 Bypass 기본값을 적용했고 실행 중인 WWW 앱도 새 빌드로 재시작했다. 실제 두 경로의 명령 실행에서 승인 요청이 없었고, 관련 테스트 42건·소스 정책·타입 검사·빌드와 독립 Opus 검토가 통과했다.

새 대화는 on-request/workspace-write로 시작했고 기존 대화도 과거 권한 설정을 유지해 세션 허용 요청이 나타날 수 있었다. 새 대화와 재개는 never/danger-full-access를 명시한다. 실제 정책 응답을 상태 표시로 전달하며, 다시 실행한 앱에서도 Bypass 기본값을 확인했다.

  • 새 대화와 저장 대화 재개가 Bypass 정책을 공유한다.
  • 화면은 서버가 응답한 실제 정책을 표시한다.
  • 빌드를 막던 보고서 테스트 3개의 구조 주석·import 순서와 실제 의존성 등록을 보완했다.
