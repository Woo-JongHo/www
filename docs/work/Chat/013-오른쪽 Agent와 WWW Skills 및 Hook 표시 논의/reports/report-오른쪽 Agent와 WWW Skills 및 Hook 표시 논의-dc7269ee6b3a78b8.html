AC-1 · 고정 Agent와 다섯 Skills

AC-2 · 근거 있는 현재 항목

정본 경로의 구조화 Skill 요청 하나만 선택한다. 문서 읽기·이름·복원·종료를 현재 실행으로 올리지 않는다.

근거 집중검사 선택·해제·다중 요청·다른 thread·historical 행동 사례

GUI의 양성 선택 강조는 새로 관찰하지 않았다.

AC-3 · Hook 기본 제외와 상세 보존

표시 변경은 Hook 실행 비활성화가 아니다.

AC-4 · 실제 Subagent와 완료 불

실제 Agent 식별자와 상태를 유지하며 일반 도구 종료로 완료를 추정하지 않는다.

근거 집중 행동·SSR 완료 체크·동일 항목 유지; 이전 Electron 합성 Native 전이

실제 모델의 하위 Agent spawn은 이 검증에서 실행하지 않았다.

AC-5 · 연결된 Plan과 Progress

현재 Native Plan의 유일한 활성 항목에 공개 설명을 연결하고 늦은 설명의 재귀속을 막는다.

근거 집중 행동·SSR 활성 항목·delta·A→B→A·비공개 추론 제외

활성 항목 산문의 GUI 동시 표시를 새로 관찰하지 않았고 Plan.md 파일·복원 미제공 자료는 임의 보충하지 않는다.

중요한 선택과 그 이유

문서 읽기와 도구 종료가 실제 실행·완료처럼 보일 수 있다.

선택 각 근거를 분리하고 명시 근거에만 선택·완료 표시를 연결한다.

판단 근거 구조화 입력과 Agent 전용 상태 필드가 서로 다른 사실을 제공한다.

감수한 점 Native가 단계·Agent 자료를 제공하지 않으면 현재 상태가 미확인으로 남는다.

다음 행동 선택 강조·활성 산문 GUI와 비필수 interleaving 표시를 후속 점검한다.

기록된 변경

  • agent-overview 순수 투영과 전용 뷰·CSS를 추가하고 기존 ResourceActivitySidebar props를 유지해 연결했다.
  • 정본 경로의 명시 Skill 요청·문서 읽기·이름 언급을 구별하고 종료·복원된 요청의 현재 선택을 해제한다.
  • Agent 상태 completed와 일반 도구 종료를 구별하며 후속 요청·실패·중단·연결 종료·historical 상태를 보존한다.
  • Native Plan의 활성 항목과 공개 산문을 묶고 계획 변경·항목 복귀·계획 이전 메시지의 늦은 delta를 재귀속하지 않는다.
  • Product·Architecture·Development·Chat 명세의 기본바와 상세 모니터 범위를 최신 구현에 맞춰 정합화했다.
  • 공식 구조 snapshot 재생성으로 만료된 현재성을 숨기지 않고 과거 이력을 보존해 재개·실제 집중 재검사·새 Opus 감사·문서 재연결을 수행했다.
  • 일반 core의 조건부 Terra fallback과 이번 최종 Opus고정, 외부 Sonnet 보조검토를 구분한 공통 문서 정합화 뒤 기능 증거를 유지하고 문서·감사 현재성만 복구했다.

요구와 결과

아래는 작성자의 요구·결과 설명입니다. 연결 근거의 서술은 별도의 검사 판정을 새로 부여하지 않습니다.

AC-1 · 고정 Agent와 다섯 Skills

WWW Agent 아래 spec/design/build/diagnose/verify를 항상 보이고 범용 목록을 제외한다.

근거 집중검사 고정 목록·범용 제외 SSR; 이전 Electron 기본바 표시

실제 다섯 스킬을 모두 호출한 시험은 아니다.

AC-2 · 근거 있는 현재 항목

정본 경로의 구조화 Skill 요청 하나만 선택한다. 문서 읽기·이름·복원·종료를 현재 실행으로 올리지 않는다.

근거 집중검사 선택·해제·다중 요청·다른 thread·historical 행동 사례

GUI의 양성 선택 강조는 새로 관찰하지 않았다.

AC-3 · Hook 기본 제외와 상세 보존

기본바에서 Hook·범용 리소스를 제외하고 상세의 Hook 상태·진단을 보존한다.

근거 집중 SSR 기본 제외·상세 보존; 이전 Electron Hook 실패/완료

표시 변경은 Hook 실행 비활성화가 아니다.

AC-4 · 실제 Subagent와 완료 불

실제 Agent 식별자와 상태를 유지하며 일반 도구 종료로 완료를 추정하지 않는다.

근거 집중 행동·SSR 완료 체크·동일 항목 유지; 이전 Electron 합성 Native 전이

실제 모델의 하위 Agent spawn은 이 검증에서 실행하지 않았다.

AC-5 · 연결된 Plan과 Progress

현재 Native Plan의 유일한 활성 항목에 공개 설명을 연결하고 늦은 설명의 재귀속을 막는다.

근거 집중 행동·SSR 활성 항목·delta·A→B→A·비공개 추론 제외

활성 항목 산문의 GUI 동시 표시를 새로 관찰하지 않았고 Plan.md 파일·복원 미제공 자료는 임의 보충하지 않는다.

중요한 선택과 그 이유

문서 읽기와 도구 종료가 실제 실행·완료처럼 보일 수 있다.

선택 각 근거를 분리하고 명시 근거에만 선택·완료 표시를 연결한다.

판단 근거 구조화 입력과 Agent 전용 상태 필드가 서로 다른 사실을 제공한다.

감수한 점 Native가 단계·Agent 자료를 제공하지 않으면 현재 상태가 미확인으로 남는다.

확인하지 못한 범위

  • GUI의 양성 스킬 강조와 활성 Plan+Progress 산문 동시 표시는 이번 공식 집중검사 담당이 새로 관찰하지 않았다. 이전 Electron 결과는 합성 Native의 역사적 보조 근거다.
  • 실제 모델 Subagent spawn·Windows·OS 한국어 IME는 이번 범위에서 실행하지 않았다. Native 사건이 제공되지 않으면 미제공/미확인으로 표시한다.
  • Plan.md 파일이나 복원되지 않은 계획을 읽었다고 표시하지 않으며 Native 계획 사건과 공개 commentary만 연결한다.
  • 독립 감사의 비필수 관찰: 같은 활성 항목에서 commentary 중 explanation plan 갱신이 끼면 다음 delta가 잠시 앞부분 없이 보이고 완료 snapshot에서 회복될 수 있다.
