Skills와 Hook 활동 사이드바

Terra가 찾은 사이드바 결함 6건을 수정하고 현재 소스에서 전체 검사와 실제 Electron·Native 표본을 통과했습니다. 작업은 독립 Terra 재검토 전이라 verifying으로 남겨 둡니다.

등록 목록이 오래된 사건과 함께 사라지거나 늦은 응답에 덮이고, 같은 사건의 여러 Skill 읽기와 Hook 중복이 화면 반응에서 손실되던 여섯 경계를 고쳤습니다. 최신 목록은 ring과 독립해 유지하고 thread scope·요청 세대·연결 수명주기 dedupe를 별도 상태로 관리합니다. 실제 Electron 화면에서는 두 Skill 행, Hook 행, 연속 강조와 모션 축소를 관찰했고 실제 설치 Native에서는 36개 Skill·3개 Hook 목록과 읽기 전용 Skill 읽기를 확인했습니다. 다만 저자와 독립된 Terra 재검토가 남아 있어 작업 완료로 전환하지 않았습니다.
