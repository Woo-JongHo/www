Skills와 Hook 활동 사이드바

사이드바005의 코드·fixture 결함을 수정했다. 최신 소스의 전체 검사와 실제 Electron 합성 GUI 11개 항목이 통과했고 독립 Terra가 PASS로 확인했다. Native 읽기 표본은 같은 실행 코드의 이전 통과를 재사용한다. Chat006과 빈 index를 보존했고 커밋·push하지 않았다. 자동 done은 사용자 지정 Terra를 수용하지 못하는 기존 core 정책 때문에 별도 미반영 상태다.
