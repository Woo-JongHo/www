Skills와 Hook 활동 사이드바

Terra 재검토 1차가 지적한 연결 복원 dedupe 초기화, 무한 상태 증가, 요청 시작 경합 세 결함을 현재 제품 경계와 fixture에서 보완했다. 집중 회귀 87건, 타입 검사, 빌드와 전체 npm run check는 현재 소스에서 통과했다. 실제 설치 Native와 Electron GUI는 각각 현재 세션의 SQLite state 초기화 실패와 앱 코드 진입 전 SIGABRT로 재시도에 실패해 AC-4와 AC-5를 완료로 판정하지 않았다. 부모가 유효한 권한·GUI 세션에서 두 probe와 사용자 지정 Terra 읽기 전용 재검토를 이어간다.

대화 복원·생성이 실제 transport 재연결처럼 게시되어 동일 연결의 Hook run dedupe가 초기화됐고, 사건·읽기·Hook 상태가 사건 수에 비례해 계속 증가했다. 목록 요청의 최신 세대도 새 요청 시작이 아니라 새 응답을 받은 뒤에만 앞선 응답을 배제해 지연된 이전 목록이 수용될 수 있었다. 실제 app-server 초기화만 연결 세대를 올리고 대화 복원은 transport 상태만 동기화한다. 전송 seq는 scalar high-water로, 활동 dedupe는 연결 세대 수명의 고정 128 KiB 필터로, UI 관찰·pulse·thread catalog는 명시한 cap으로 제한했다. scope별 요청 generation을 시작 시점에 획득해 오래된 성공·실패를 게시 전에 버리며, 실제 대화 전환과 요청 경합 순서를 fixture와 probe에 고정했다.
