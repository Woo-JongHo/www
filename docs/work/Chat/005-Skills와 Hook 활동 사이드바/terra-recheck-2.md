2. **무한 증가 — 크기는 해결, 새 활동 정확성은 미해결.** 일반 사건 20,000건은 약 21ms에 처리됐고 순번은 scalar 하나, dedupe 필터는 128KiB였습니다. 서로 다른 Hook 20,000건은 약 190ms에 처리됐으며 pulse는 최대 512개로 유지됐습니다. 그러나 이 중 새 실행 한 건이 필터 충돌로 누락됐습니다. 고유 활동마다 필터 128KiB를 복사한다는 비용도 남습니다. 이 수치는 해당 Bun 합성 실행의 측정값입니다.

3. **요청 시작 시 이전 응답 무효화 — 코드 경로에서 해결.** main이 cwd와 요청 범위별 최신 세대를 시작 시 저장하고, 성공과 실패 모두 발행 전에 검사합니다. thread 목록은 workspace 목록보다 우선합니다. 지연·실패 fixture는 준비돼 있으나 이번 Electron 실행이 실패해 실제 IPC 시나리오는 독립 재실행하지 못했습니다. [main.ts](../../../../src/main.ts#L171)
