# 구현과 통합 작업

- AC-1·AC-3: Ovis 코드 출처 확인, 채팅 row/입력 상태 이식, Markdown·복사·인용·대화별 초안/읽기/펼침 통합.
- AC-2: Native schema 확인, 목록·새대화·읽기·resume IPC와 과거 snapshot 투영, guard·실패·절단 검사.
- AC-4: 기존 변경 보존과 타입 기준선 수정, 공식 검사·실제 Electron 합성 시나리오·가능한 Native 표본, 문서 영향과 독립 검토·저작 보고서.
- root는 원격 문서·도구 설정·통합 검증을 소유한다. 대화 경계와 UI 작성은 겹치지 않는 파일 책임으로 병렬 진행한다. 공유 API 변경은 먼저 합의한다.
