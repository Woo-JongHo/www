# Mac과 Windows 실사용 및 검증 신뢰성 완성

## 요청과 목적

사용자가 표 1~8 전체를 승인했다. Mac 공통 기능과 별도 Windows checkout을 병렬 구현하며 실제 실행·IME와 독립 Opus 감사를 구분해 완료한다. 기존 별도 Skills 번역은 보존한다.

사용자의 직접 요청으로 접수했다. 요청 식별값은 work.json의 workflow.requestHash에 보존한다.

## 범위

변경 경로·표면·검증 명령과 커밋·게시 권한은 work.json의 workflow.authorization을 따른다. 범위 확대는 기존 권한으로 간주하지 않는다.

## 수용 기준

정의와 필수 여부의 정본은 work.json이다. 관련 기준: `AC-1`, `AC-2`, `AC-3`, `AC-4`, `AC-5`, `AC-6`, `AC-7`, `AC-8`.

## 결정과 열린 질문

작업 접수는 구현 완료가 아니다. 재개 시 같은 UUID와 현재 증거를 확인한다.
