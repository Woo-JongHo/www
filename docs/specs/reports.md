# 작업 리포트

## REPORTS-1 목록과 읽기

사이드바 리포트를 누르면 선택 프로젝트의 보고서 이력을 읽는다. 작성자가 남긴 보고서와 하네스가 생성한 자동 기록을 구분한다. 제목·요약 검색, 최신순 목록과 보고서 선택을 제공한다. 읽기 프로젝트는 진행 중 Native 대화와 별도로 선택할 수 있다. 전환 뒤에도 대화의 초안·선택·펼침·읽기 위치를 보존한다.

목록은 리포트 화면이 열린 동안 주기적으로 갱신하고 새로고침도 제공한다. 비어 있는 프로젝트, 일부 손상 기록의 경고, 목록 실패와 선택 보고서 읽기 실패를 구분한다. 다른 프로젝트를 선택하면 이전 선택·내용을 새 프로젝트의 결과로 표시하지 않는다.

## REPORTS-2 내용과 근거

목표와 한 문장 요약, 변경 전후 비교, 실제 변경과 선택 이유, 당시 수용 기준·검사·검토, 한계와 다음 행동을 정적 본문에서 읽는다. 자동 기록은 저작하지 않은 설명을 발명하지 않는다. 저장 당시 done인 작업만 완료로 표시한다. 코드·기준 또는 작업 기록이 달라지면 과거 기록임을 표시한다.

## REPORTS-3 안전한 HTML과 내보내기

보고서 JSON과 독립 HTML은 같은 작업 폴더 reports에 이력으로 보존한다. 앱에서는 스크립트·네트워크·상위 창 이동 권한이 없는 iframe에서 읽는다. 본문 입력은 escape하며 임의 HTML을 실행하지 않는다. ID만 허용된 IPC로 전달하고 저장소 밖 경로·symlink·과대 파일을 거부한다. 내보내기는 main의 파일 저장 대화상자가 지정한 경로에 HTML 사본을 쓴다. 독립 HTML은 인터넷 없이 읽고 좁은 화면과 인쇄에서 필수 내용을 유지한다.

## REPORTS-4 수명주기

검증·검토·개발 호스트 종료·업무 완료 사건에서 실제 자동 기록을 저장한다. reportHook 실패는 핵심 기록 저장 및 실행 결과와 별도로 반환한다. 저자는 작업 반환 전 보고서를 직접 작성하고 공식 typed 경로로 접수한 작업 완료는 현행 소스·기준·기록의 저작 보고서를 요구한다. 기존 검사·독립 검토 조건은 유지한다. 전역 호스트 훅의 설치나 강제 종료 시 콜백 실행까지 제공한다고 표현하지 않는다.

## REPORTS-5 Native 자동 판단과 저작

Native 공개 답변과 종료 사건을 모두 받으면 별도 읽기 전용 LLM이 규모·정보 가치를 판단한다. 필요하면 구조화 서술로 보고서를 저장하고 앱 목록에 반영하며, 작은 대화는 이유와 함께 생략한다. 자동 처리는 기본으로 켜고 토글·상태·명시 재시도를 제공한다. 대화를 막지 않으며 사건 당시 프로젝트에 고정한다. 중복 턴은 재생성하지 않고 재시작 중단을 성공으로 표시하지 않는다. 원문 입력은 제한된 메모리에만 두고 추론·명령 출력 원문을 전달하지 않는다. 모델 판단 오류·타임아웃·저장 실패를 별도 상태로 표시한다. Native 종료만으로 업무를 done이나 검증 통과로 바꾸지 않는다. 자세한 제한은 [보고서 계약](../skills/REPORTS.md#native-답변-뒤-자동-저작)을 따른다.

## REPORTS-6 독자를 위한 이야기와 판단 근거

첫 화면은 자연스러운 prose 작업 이야기와 결론·확인 범위·필수 차단·다음 행동을 제공한다. 요구별 결과를 대응하고 검사는 대상·방법·기대·관측·미확인을 보여 준다. 중요한 선택·방향 전환은 실제 기록이 있을 때만 설명한다. 미기록 자료는 만들어 채우지 않는다. 과거 검사 결과와 현행 적용성을 분리하고 해시·UUID·원시 이력은 상세로 내린다. 구형 보고서는 원본을 바꾸지 않고 읽기 양식만 개선한다. 정확한 작성 경계는 [보고서 계약](../skills/REPORTS.md#독자가-판단하는-보고서-양식)을 따른다.
