# 생태계 지도

## ECOSYSTEM-1 사이드바와 화면 전환

왼쪽 사이드바의 생태계를 누르면 WWW 자체의 구조 지도를 연다. 대화로 돌아올 때 입력 초안·대화 상태·명령 펼침·읽기 위치를 유지한다. 지도는 선택한 작업 폴더를 분석하는 기능이 아니며 WWW 번들에 포함된 구조 안내다.

## ECOSYSTEM-2 구조와 근거

앱 실행, 개발 절차, 기록과 검토, 후속 방향을 영역과 색상으로 구분한다. 노드 선택 시 역할 설명, 저장소 기준 근거 경로, 들어오고 나가는 연결의 의미를 표시한다. 후속 방향은 점선으로 표시하고 구현 완료로 설명하지 않는다. 실제 실행 상태나 자동 소스 분석으로 표현하지 않는다.

## ECOSYSTEM-3 탐색

노드와 관계 버튼으로 상세 대상을 바꾸고 검색·영역 필터로 일치 노드를 강조한다. 일치 결과가 없으면 빈 결과와 초기화 방법을 표시한다. 지도 확대·축소·전체 보기, 배경 드래그와 스크롤을 지원한다. Tab으로 노드에 초점을 옮기고 Enter와 Space로 선택한다.

## 범위

정적 안내 데이터는 src/ecosystem.ts, 표현은 src/ecosystem-view.tsx가 소유한다. 구조가 바뀌면 정본 문서와 함께 안내를 갱신한다. 서버 색인·Canvas 편집·GitHub 자동 동기화는 후속 방향이다.
