# 생태계와 코드 설계도

## ECOSYSTEM-1 사이드바와 화면 전환

왼쪽 사이드바의 생태계를 누르면 WWW Node Map의 `기능·책임 지도`를 기본으로 연다. 대화로 돌아올 때 입력 초안·대화 상태·명령 펼침·읽기 위치를 유지하고 지도로 돌아오면 경로·선택·검색·배율·이동도 유지한다. 선택한 작업 폴더를 분석하는 기능이 아니며 WWW 번들에 포함된 소스 snapshot과 수동 안내다.

## ECOSYSTEM-2 구조와 근거

코드 설계도는 `docs/architecture/structure.json`의 안정 구조 ID와 단일 부모 계층을 따른다. 최초에는 `arch.www`의 직계 자식만 표시한다. branch 선택은 해당 ID로 진입해 직계 자식을 보여 주며 leaf 선택은 같은 ID의 역할·구성 수를 지도 아래 선택 요약에 표시한다. 자세히 보기를 명시적으로 열면 명세 요구·구현 선언·검증 참조를 상세에 표시한다. `arch.www → arch.chat → arch.chat.sessions → arch.chat.sessions.restore`를 세 번 선택해 도달할 수 있다. 명세 요구 ID와 실제 문서 행, 구현 파일과 선언 행, 연결된 테스트와 선언 행을 읽는다. 선언 등록은 테스트 실행이나 요구 충족의 증명이 아니다.

기본 `내부 구성` 보기는 부모와 직계 자식의 포함 관계만 표시한다. `코드 의존 관계` 보기에서는 계층선을 숨기고 현재 단계의 직계 자식 사이 실제 import를 책임 ID로 축약해 참조하는 쪽에서 참조되는 쪽으로 표시한다. 참조 강조 대상으로 현재 단계의 책임 하나를 선택하면 들어오는·나가는 참조만 표시하고 선택 요약을 갱신한다. 간선 번호와 사람이 읽는 관계 목록을 연결한다. runtime·mixed·type의 개수를 구분하며 타입 전용은 점선이다. 같은 책임을 공유하는 여러 파일의 내부 참조를 서로 다른 책임 경계로 그리지 않는다. 선택한 책임 범위 밖 참조는 상세에 원문·파일·행과 대상 ID를 표시한다. 대상 선택은 그 부모 경로와 선택 ID를 함께 갱신한다.

별도 `개념 처리 관계`는 앱 실행, 개발 절차, 기록과 검토, 후속 방향을 영역과 색상으로 구분한다. 실제 source 근거가 있는 경우 같은 안정 구조 ID로 담당 코드 지도를 열고 근거가 없으면 미제공을 표시한다. 후속 방향은 점선으로 표시하고 구현 완료로 설명하지 않는다. 이 수동 안내·정본 부모 계층선·실제 정적 import를 실행 trace로 혼동하지 않게 구분한다.

## ECOSYSTEM-3 탐색

구조 ID·요구 ID·제목·구현 및 테스트 파일의 전역 검색을 제공하며 검색 결과는 해당 경로를 연다. 빈 검색은 현재 계층을 유지하며 결과가 없으면 안내와 초기화를 표시한다. 현재 구조 ID, ancestor breadcrumb, 뒤로와 전체 복귀를 제공한다. 지도 확대·축소·현재 계층 크기 맞춤, 배경 드래그와 스크롤을 지원한다. Tab·방향키·Home·End로 코드 노드에 초점을 옮기고 Enter와 Space로 branch 진입·leaf 선택을 수행한다. 현재 단계의 직계 자식은 viewport 폭과 표시할 간선 수에 따라 결정적으로 배치한다. 부모와 하위 노드는 모두 360×112px이며 제목·역할 두 줄 요약·하위 구성 또는 담당 코드 수를 같은 위치에 표시한다. 원문 설명과 안정 ID는 상세와 노드 툴팁에서 읽는다. 충분한 폭의 구성 보기는 최대 3열 2행으로 여섯 책임을 배치한다. 좁은 창은 한 열을 유지하고 글자를 축소하지 않으며 지도 내부와 그래프 아래 상세를 세로 스크롤해 접근한다. 의존선은 오른쪽 출발·왼쪽 도착 포트를 분리하고, 간선 수에 따라 넓어진 열 옆·행 위 통로에서 각자 다른 경로를 사용한다. 서로 반대 방향의 선에 같은 통로·포트를 재사용하지 않는다. 모든 노드를 한 화면에 넣기 위해 자동 축소하지 않으며 큰 지도는 내부 스크롤한다. 계층 이동과 viewport 크기 변경은 배율과 이동 위치를 다시 맞추며, 일반 렌더에서는 사용자 배율·이동을 보존한다.

## 범위

지도 기본 화면은 64px 화면 전환 rail과 중앙 지도, 선택 요약으로 구성한다. 프로젝트·대화 목록은 탐색 열기로 원래 사이드바를 열 때 표시하고, Chat·리포트로 전환하면 기존 사이드바를 복구한다. 탐색 열림은 지도 상태로 보존한다. 노드·검색·부모·참조 선택은 닫힌 상세를 자동으로 열지 않는다. 선택 제목·역할·하위 구성/담당 코드 수는 지도 아래 작은 요약에 표시한다. 상세는 자세히 보기를 명시적으로 누르면 열고, 이미 열어둔 상세는 후속 노드 탐색에서 유지한다. 개념 안내의 담당 코드 보기는 명시적인 상세 요청이다. 제목·경로·검색·관계·배율 도구는 압축해 지도 면적을 확보하며 snapshot 메타데이터는 기본 화면에서 숨긴다. 역할과 책임, 하위 구성별 역할·진입, 하위 포함 코드·명세 수, 담당 파일, 참조하는 책임과 참조받는 책임을 먼저 읽는다. 직접 명세·구현·검증 등록은 접힘 근거 영역에 보존하며 하위 포함 집계와 구별한다. 대화 세션은 초안·읽기 상태, Native 목록·복원, Native 요청 구성의 세 하위 책임과 담당 파일을 연결한다. 넓은 창에서는 360px 오른쪽 패널을 사용하고 좁거나 낮은 창은 지도 아래 상세를 스크롤한다. ancestor 복귀는 상세를 닫아 지도 영역을 확보한다. 닫기·Escape 뒤 선택 노드로 초점을 돌려준다. 숨긴 지도는 레이아웃과 0치수 fit에서 제외하고 두 지도 탭의 상태를 유지한다.

자동 추출은 scripts/generate-architecture.ts, 계층 탐색·검색·의존 집계는 src/architecture-tree.ts, 기존 파일 참조 API·배치는 src/architecture.ts, 생성 자료는 src/architecture.generated.json, 표현은 src/ecosystem-view.tsx와 src/ecosystem.css가 소유한다. 수동 안내 데이터는 src/ecosystem.ts에 유지한다. 구조가 바뀌면 [코드 설계도](../CODE_BLUEPRINT.md)와 정본 문서를 함께 검토한다. 서버 색인·Canvas 편집·GitHub 자동 동기화는 후속 방향이다.
