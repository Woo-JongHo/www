# 생태계와 코드 설계도

## ECOSYSTEM-1 사이드바와 화면 전환

왼쪽 사이드바의 생태계를 누르면 WWW 자체의 코드 설계도를 기본으로 연다. 대화로 돌아올 때 입력 초안·대화 상태·명령 펼침·읽기 위치를 유지한다. 선택한 작업 폴더를 분석하는 기능이 아니며 WWW 번들에 포함된 소스 snapshot과 수동 안내다.

## ECOSYSTEM-2 구조와 근거

코드 설계도는 계층 개요와 모듈 상세를 제공한다. 계층의 분류·역할은 사람이 정의하며 모듈 참조는 현재 TypeScript에서 추출한다. 개요에서 계층 간 방향 연결을 묶어 보여 주고 모듈 선택 시 관련 연결을 강조한다. 화살표는 참조하는 쪽에서 참조되는 쪽으로 향한다. 타입 전용 참조는 점선이고 값·혼합 참조와 구분한다.

모듈 상세에는 파일·전체 행 범위·내용 해시, 들어오고 나가는 참조의 파일·시작/끝 행·원문 구문을 표시한다. 빌드 전에 결정적인 snapshot을 생성하며 해석 실패를 이전 결과의 성공으로 감추지 않는다. 외부 패키지·생성 자료·범위 밖 참조의 제외와 실행 추적이 아니라는 한계를 표시한다.

별도 생태계 안내는 앱 실행, 개발 절차, 기록과 검토, 후속 방향을 영역과 색상으로 구분한다. 후속 방향은 점선으로 표시하고 구현 완료로 설명하지 않는다. 이 수동 안내를 자동 import 분석과 혼동하지 않게 보기와 안내 문구를 구분한다.

## ECOSYSTEM-3 탐색

파일·역할 검색과 계층 필터로 모듈을 탐색한다. 일치 결과가 없으면 빈 결과와 초기화 방법을 표시한다. 계층 개요에서 모듈을 선택하면 모듈 상세로 이동한다. 지도 확대·축소·전체 보기, 배경 드래그와 스크롤을 지원한다. Tab·방향키·Home·End로 코드 노드에 초점을 옮기고 Enter와 Space로 선택한다. 좁거나 낮은 창에서는 그래프 아래의 근거 패널까지 세로 스크롤해 접근한다.

## 범위

자동 추출은 scripts/generate-architecture.ts, 결정적 탐색·배치는 src/architecture.ts, 생성 자료는 src/architecture.generated.json, 표현은 src/ecosystem-view.tsx와 src/ecosystem.css가 소유한다. 수동 안내 데이터는 src/ecosystem.ts에 유지한다. 구조가 바뀌면 [코드 설계도](../CODE_BLUEPRINT.md)와 정본 문서를 함께 검토한다. 서버 색인·Canvas 편집·GitHub 자동 동기화는 후속 방향이다.
