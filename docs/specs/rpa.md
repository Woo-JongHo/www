# RPA 표준 화면

RPA 개발 프로필이 있는 프로젝트의 사이드바에서 **RPA 표준**을 연다. 선택한 프로젝트의 지도와 Core, 로컬 실행 근거를 같은 화면에서 본다.

- `rpa-workspace.json`과 업무 지도의 프로젝트 ID를 대조한다. 지도 순서대로 Process, Task, Unit 주소와 부수효과, 중단, 재실행 정책을 표시한다.
- `core/seed-manifest.json`의 지원하는 공통 Core 버전 0.2.0·0.2.1의 관리 파일 7개를 정본 지문 및 실제 바이트와 대조한다. 프로젝트별 Core 모듈은 관리 파일 수에 포함하지 않는다.
- `logs/runs`에서 가장 최근 실행 폴더의 `result.json`을 읽는다. 업무 실행 상태, 종료 코드, Unit 시도, 공통 로그 파일 5종의 유무를 표시한다. 최신 실행에 종료 근거가 없으면 해당 상태를 유지한다. 로컬 기록이 없거나 읽을 수 없으면 각각 표시한다. 실행 디렉터리가 1,000개를 초과하면 조회 한도를 표시한다.
- 조회에서 RPA 코드나 Python 검사를 실행하지 않는다. 화면의 실행 결과는 운영 환경 수락 증거와 구분한다.

지도에 연결된 대응 Case는 해당 Unit 아래에서 상황·기대 결과·다음 조치·재실행 조건을 펼쳐 확인한다. 이 안내는 사전에 정의한 대응 기준이며 실행 중 실제 발생을 판정한 결과와 구분한다.
