# 데스크톱 프로필

[공통 작업 기록 계약](../WORKFLOW.md)에 추가되는 현재 유일한 프로젝트 유형 프로필이다. WWW 자체 개발과 이후 데스크톱형 하위 프로젝트에 적용한다.

## 조건부 스택 경계

데스크톱 백엔드는 확정되지 않았다. 선택된 백엔드가 Electron이면 main/preload/renderer, context isolation, IPC 허용 목록과 프로세스 수명주기를 검토한다. Tauri이면 Rust command/event 경계, capability, sidecar 또는 직접 spawn 정책을 검토한다. 두 구현을 동시에 의무화하거나 Tauri 이주를 전제하지 않는다. React 뷰와 공유 계약은 가능한 한 백엔드 중립으로 유지한다.

## 필수 관점

- 로컬 agent 프로세스 시작·중단·EOF·오류와 불확실한 결과를 구분한다.
- JSON-RPC 요청 ID의 문자열·숫자 형식을 보존한다.
- 승인·거절·지원하지 않는 응답, 중복 입력 방지, 종료 시 미결 승인을 검증한다.
- UI 영향은 키보드, 포커스, 로딩·오류·빈 상태와 한국어 문구를 확인한다.
- 배포·진단·패키징이 실제 범위에 들 때만 `ops` 영역을 선택한다.
- 실제 데스크톱 QA를 실행하지 않았다면 합성 테스트와 구분해 한계로 기록한다.
