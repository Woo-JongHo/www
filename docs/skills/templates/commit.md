이 양식은 준비 요약용이다. 작성만으로 stage·commit·push를 승인하거나 실행하지 않는다. 작은 변경은 같은 항목을 대화로 제시해도 된다.

## 메시지 제안

- 제목: [한국어 변경 결과 문장]

## 현재 판정

[준비 완료·실행 미승인 / 검증 부족 / 범위 충돌 / 실행 승인됨 중 실제 상태와 이유]

명시적 “커밋해” 실행 요청의 기본값은 commit + push이며 “로컬에만” 요청은 push를 생략한다. 이 양식 작성만으로 실행 권한을 만들지는 않는다. 커밋 성공·원격 push 확인·서버 색인은 각각 보고하고, force push·merge·release는 포함하지 않는다.
